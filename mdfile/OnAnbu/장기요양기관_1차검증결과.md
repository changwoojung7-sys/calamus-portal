## 1. 운영 적재 완료, 공개 전환 없음

- 배치: `03242aaeef5ab322e234fa5a1ee64cafdaf062b3da55af8c4917beafbf5661a4`
- 기관 30,595 · 서비스 49,324 · 인력 49,162 · 인력 키워드 근거 135,434 · 서비스코드 39개.
- 표별 전체 건수뿐 아니라 모든 행의 적재값을 로컬 변환 결과와 대조했다.
- 배치는 `STAGED`, 적재 검증은 `VERIFIED`, 공개 일시는 NULL이다.
- 원천 및 검토 이력 8개 표에 RLS 적용·일반 사용자 조회 차단을 확인했다.
- 기존 HIRA 병원 자료·병원 키워드·공개 검색은 변경하지 않았다.
- 적재 내용 검증이 완료된 것이며, 모든 기관이 현재 운영 중이거나 실제 인력이 현재 근무함을 보증하지 않는다.

## 2. 검토 대상과 결과

기존 품질 사유 378기관에 불완전 상세주소를 추가 점검해 총 **383기관, 387개 문제 항목**을 검토했다. 문제 항목은 한 기관에 중복될 수 있다.

| 항목 | 건수 |
|---|---:|
| 지역명 문자열 누락 | 376 |
| 상세주소 빈 값 | 2 |

| 지역코드 빈 값 | 1 |
| 정원·인력에 서비스 원천행 없음 | 2 |

| 검토 결과 | 항목 수 | 설명 |
|---|---:|---|
| SOURCE_CROSSCHECKED | 374 | 지역명 보완 근거 확보. 원본 내 같은 지역코드+주소 대조 130, 공식 코드+주소 대조 244 |
| PROPOSED | 1 | 샬롬의집의 과거 법정동 코드가 공식 자료와 일치하나 상세주소 추가 확인 필요 |
| UNRESOLVED | 12 | 9기관의 주소·서비스·지역 정보 미확정 |

374기관의 지역명 **제안값과 근거를 별도 보관**했으며, 원본 누락값을 덮어쓰지 않았다. 나머지 추가 확인 대상은 9기관이다. 샬롬의집의 PROPOSED 1항목은 이 9기관 안에 포함된다.

공식 참조는 [행정표준코드 법정동코드 목록/전체자료](https://www.code.go.kr/stdcode/regCodeL.do)를 사용했다. 읍면동 단위 연결용 코드 14,144개를 확보했고, 미해결 지역명에 대해 245기관의 코드가 공식 자료와 연결됐다(244개 주소 대조 완료, 과거 코드 1개 보류). 파일의 시도 2자리 + 시군구 3자리 + 법정동 3자리와 공식 10자리 코드의 읍면동 단위(끝 00)를 대조했으며 기관코드에서 지역을 추정하지 않았다.

공식 참조의 조회 시각과 ZIP 해시를 근거에 저장했다. 공식 코드의 폐지 표시는 **지역코드의 폐지이지 기관의 폐업이 아니다**. 현재 코드자료와 과거 기관자료의 시점 차이도 고려해야 한다.
