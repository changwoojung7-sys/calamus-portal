# 홈 AI 정밀진단 전체 구현 프로세스

> 현행 기준: 2026-09-28 (AI 문지기 캐시 게이트 및 정밀 팩트 필터링 고도화 전면 반영)  
> 실행 버전: **ai-discovery-v2-gatekeeper-cache**  
> 운영 Edge Function: **ai-care-search version 35**

---

## 1. 목적

AI 정밀검색은 사용자가 입력한 자연어 질문을 ChatGPT·Gemini·Perplexity 등 복수의 첨단 AI에 전달하여 각 모델이 추천하는 실제 병원을 수집하고, 온안부 심평원(HIRA) 마스터에 실재하며 유효한 대표전화가 확인된 병원만 화면에 제공하는 고신뢰성 하이브리드 추천 기능이다.

핵심 목적은 다음과 같다.

1. “무릎치료”, “허리통증”, “항암 후 요양” 같은 자연어 질문을 요양·재활 카테고리로 미리 제한하지 않는다.
2. 종합병원·병원·한방병원·의원·요양병원·호스피스 완화의료 시설을 AI가 질문에 맞게 폭넓게 발견하게 한다.
3. 자체 문지기 알고리즘을 통해 외부 AI 호출 비용과 레이턴시를 0원/0.05초로 극소화한다.
4. AI 추천 시설 중 유선 대표전화가 확인되지 않거나 필수 의료조건이 없는 유령/가상 병원을 원천 차단한다.
5. AI 원문, 제품별 순위, 추천 이유를 분석 자산으로 영구 보존한다.
6. HIRA 병원 식별정보, 호스피스 3대 서비스, 승인 기관회원 콘텐츠를 사후 결합해 결과 신뢰도를 극대화한다.
7. 기본 병원검색 쿼리와 필터는 변경하지 않고 독립성을 유지한다.

## 2. 현행 핵심 결정

| 항목 | 현행 결정 |
| :--- | :--- |
| **비회원 권한 정책** | **하이브리드 프리미엄 방식**: 비회원은 1회 무료 체험 제공, 2회째 시도 시 친절한 안내와 함께 간편 로그인 유도 |
| **질문 지역 사전 감지** | 질문 내 특정 지역명이 없을 경우 화면의 현재 기준 지역(예: 경기도 용인시) 사용 여부 사전 확인(confirm) 후 주입 |
| **문지기 캐시 게이트** | 순수 TypeScript 기반 의도 지문(`intent_fingerprint`)을 생성하여 동일 질문 시 외부 AI 호출 없이 **0원 / 0.05초** 즉각 반환 |
| **부정 표현 처리** | `투석 필요 없음`, `재활 불필요` 등 부정 표현을 감지하여 필수조건(Hard Filter)에서 자동 제외 |
| **AI 입력 후보** | HIRA 후보 20곳을 미리 보내지 않고 AI 자율 발견(First-Discovery) 유지 |
| **사용자 질문** | PII 마스킹(한국어 조사 결합 및 존칭 정규식 강화) 후 문구 그대로 각 AI에 전달 |
| **AI 출력 계약** | 제품별 최대 Top 5, 병원명·주소·전화·원순위·2~3문장 추천 이유 (고정 JSON) |
| **최종 병원 검증** | AI 응답 후 병원명으로 **hosapi_hospital** 대조 + **유선 대표전화 실측 검증 (유령 병원 즉시 탈락)** |
| **호스피스 3대 서비스** | 보건복지부 지정 127개 호스피스 데이터와 매칭하여 입원형/가정형/자문형 및 인가병상 카드 자동 연계 |
| **기관회원 정보** | `hospital_provider_profiles`에 격리 보존된 특화진료·장비·식사·비급여를 사후 결합 |
| **B2C 보호자 카드 UI** | **종합 AI 적합도 (CareFit Score)** 단일 뱃지 거대 강조 + 추천 이유는 **아코디언 토글**로 인지 부하 해소 |
| **B2B LUVIS UI** | 5대 진단 축 **AI 가시성 방사형 레이더 차트** + **원스톱 액션 솔루션 패널** 장착 |
| **통합 순위** | 평균 AI 원순위 → 추천 AI 수 → ykiho (광고비·가입 여부 무관 순수 객관 순위) |

## 3. 기본검색과의 분리

```text
기본검색
  화면 지역/종별/특수필터
  → 기존 HIRA 검색 RPC
  → 기존 거리·광고·정렬
  → 지도와 병원카드

AI 정밀검색
  사용자 자연어 질문 (지역 확인)
  → 자체 문지기 의도 지문 생성 (intent_fingerprint)
  → 0원/0.05초 캐시 게이트 (적중 시 즉시 반환)
  → 미적중 시 다중 AI 병렬 발견 (ChatGPT·Gemini·Perplexity)
  → 병원명 DB 매칭 & 유선 대표전화 하드 필터링
  → 호스피스 3대 서비스 및 기관정보 사후 결합
  → CareFit 종합 순위 산정
  → 보호자 아코디언 리포트 & LUVIS 레이더 차트
```

- AI 검색을 실행해도 기본검색의 SQL, 기존 필터 상태와 기본 목록 페이지네이션을 변경하지 않는다.
- AI 결과를 기본검색 필터로 임의 제거하거나 기본검색 광고 순서로 재정렬하지 않는다.
- `AI_DISCOVERY_ENABLED=false` 플래그를 통해 비상 시 기존 폐쇄형 HIRA 후보 기반 정밀검색으로 즉시 롤백 가능하다.

## 4. 전체 실행 흐름

```text
 1. 브라우저 요청 (자연어 질문 + 지역 참고값 + 세션 식별자)
 2. 질문 내 지역 사전 감지 및 확인 (미포함 시 기준 지역 자동 주입 confirm)
 3. 비회원 1회 무료 체험 권한 판정 (2회째 시도 시 로그인 모달 유도)
 4. Edge 요청·Origin·레이트 리밋 검증 (consume_ai_care_quota)
 5. 질문 PII 마스킹 (이름, 전화, 나이, 조사 결합 정규식)
 6. 자체 문지기 알고리즘(intentClassifier.ts) 의도 추출 & 부정표현 배제
 7. [캐시 1단계] 의도 지문(intent_fingerprint) 0원/0.05초 캐시 게이트 조회
    ├─ 적중 시: 외부 AI 호출 없이 기존 검증 지식 즉시 결합 반환 (0원, 0.05s)
    └─ 미적중 시: 다음 단계 진행
 8. search_logs 원장 생성
 9. 관리자 AI 엔진 설정 및 활성 API 키 조회
10. [캐시 2단계] 24시간 원문 캐시 조회
11. 캐시 미적중 AI 제품 병렬 호출 (ChatGPT, Gemini, Perplexity)
12. 공급자별 원본 응답 및 토큰 선저장 (ai_response_logs)
13. JSON 파싱 및 추천 병원 추출
14. 병원명 DB 매칭 & 유선 대표전화(유령 병원) 하드 필터링 (selectUniqueMatch)
15. HIRA 상세 인프라, 호스피스 3대 서비스, 승인 기관회원 프로필 사후 결합
16. 공급자별 결과·제외 사유·evidence 저장 (ai_recommendation_evidences)
17. 종합 AI 적합도(CareFit Score) 산정 및 병원별 통합 Top 5 요약 생성
18. 화면 제공: B2C 보호자 카드(아코디언 토글), B2B LUVIS 방사형 차트
```

## 5. 세부 단계별 구현 명세

### 1단계: 브라우저 요청 & 지역 사전 감지
- **aiCareSearchClient**는 사용자의 질문을 서버로 전송하기 전 질문 텍스트에서 지역 키워드를 사전 감지한다.
- 질문에 명시적 지역이 없고 화면에 선택된 지역이 있을 경우, `"현재 선택된 [경기도 용인시] 기준으로 검색할까요?"` 안내를 띄워 사용자의 확인을 거쳐 명확한 지역명을 질문에 자동 주입한다. (타지역 병원 추천 환각 원천 차단)

### 2단계: 비회원 1회 무료 체험 (하이브리드 프리미엄)
- 로컬 스토리지 및 세션 기반으로 비회원의 정밀추천 사용 횟수를 추적한다.
- **1회차**: 회원가입 없이 즉시 무료 체험을 제공하여 질문 데이터 수집과 서비스의 기술적 효용감을 극대화한다.
- **2회차 이상**: 친절한 안내 메시지와 함께 카카오/네이버 간편 로그인 모달을 호출하여 자발적 회원 전환을 유도한다.

### 3단계: 요청 보안 및 정밀 PII 마스킹
- **ai-care-search/index.ts**에서 Origin, CORS, 쿼터(`consume_ai_care_quota`)를 방어한다.
- **piiMasker.ts**: 한국어 조사(`은/는/이/가/을/를/와/과`) 및 쉼표와 결합된 환자 이름, 존칭, 나이, 전화번호, 주민등록번호 패턴을 정규식으로 완벽 마스킹 처리하여 외부 AI 프롬프트 및 공개 로그 전송을 차단한다.

### 4단계: 자체 문지기 알고리즘 & 0원 캐시 게이트 (`intentClassifier.ts`)
- 외부 유료 모델(Ollama, Cloudflare 등)에 의존하지 않고, 순수 TypeScript 기반 결정론적 규칙으로 의도를 추출한다.
- **부정 표현 처리**: `투석 필요 없음`, `재활치료 불필요` 등 부정 문맥을 인식하여 필수조건(Hard Filter) 플래그에서 자동 제외한다.
- **의도 지문(`intent_fingerprint`) 생성**: `[시/도 + 시/군/구 + 필수조건 + 종별]`을 조합한 고유 해시 지문을 생성한다.
- **0원 캐시 게이트**: 동일 의도 지문으로 이미 검증된 지식이 DB에 존재할 경우, 외부 LLM 3곳을 호출하지 않고 기존 검증 결과를 사후 결합하여 **0원, 0.05초** 만에 초고속 응답을 반환한다.

### 5단계: 다중 AI 병렬 호출 및 고정 출력 계약
캐시 미적중 시 관리자 설정에 등록된 활성 AI 공급자를 병렬 호출한다.

- **ChatGPT (gpt-5.6-luna)**: 종합 심층 소견, 선택 가이드라인, 상담 시 필수 확인사항.
- **Gemini (gemini-3.8-flash)**: Google Search Grounding 기반 공식 홈페이지 및 신뢰 출처 검색.
- **Perplexity (sonar)**: 실시간 웹 인덱스 및 최신 공개 특화 정보 비교.

모든 모델은 다음 고정 JSON 계약을 강제한다:
```json
{
  "answer": "환자 상황, 병원 선택 기준, 추천 우선순위, 상담 확인사항을 포함한 종합 안내",
  "recommendations": [
    {
      "name": "공식 병원명",
      "address": "도로명 주소",
      "telephone": "유선 대표전화",
      "rank": 1,
      "reason": "이 병원을 추천하는 이유 2~3문장"
    }
  ]
}
```

### 6단계: 병원명 DB 매칭 및 대표전화(유령 병원) 하드 필터링
- **match_ai_discovered_hospital**:
  1. 병원명 공백·특수문자 정규화 후 `hosapi_hospital` 대조.
  2. 질문 지역과의 거리·주소 일치도 검증.
- **유령 병원 하드 필터링 (`selectUniqueMatch`)**:
  - AI가 추천한 병원 중 **유효한 유선 대표전화가 확인되지 않거나 심평원 마스터 전화번호와 매칭되지 않는 시설은 추천 후보에서 즉시 탈락(제외)** 처리한다.
  - 이를 통해 AI가 그럴듯하게 지어내는 폐업 병원이나 가상 시설의 노출을 원천 차단한다.

### 7단계: 사후 정보 결합 (호스피스 3대 서비스 & 기관 프로필)
- **HIRA 마스터**: 공식 종별, 허가 병상수, 평가 등급, 전문 장비.
- **호스피스 완화의료 3대 서비스 (`hospice_services.json`)**:
  - 전국 127개 지정 기관 매칭을 통해 `입원형`, `가정형`, `자문형` 3대 서비스 카드 및 인가 병상수, 건강보험 적용 간병보조인력 운영 여부 결합.
- **승인 기관회원 프로필 (`hospital_provider_profiles`)**:
  - 영구 격리 보존된 특화진료 태그, 식사 서비스, 비급여 항목 결합.

### 8단계: 종합 AI 적합도(CareFit Score) 산정 및 통합 순위
- 공급자별 추천 결과를 `ykiho` 기준으로 병합한다.
- 1차: AI 원순위 평균 ➔ 2차: 추천한 AI 제품 수 ➔ 3차: ykiho 순서.
- 최종 **Top 5**를 선별하고 종합 AI 적합도(**CareFit Score**)를 도출한다.

## 6. 화면 제공 시스템

### 1. B2C 보호자 카드 UI (인지적 피로도 해소)
- 위급하고 불안한 보호자가 수많은 텍스트에 질리지 않도록 병원 카드 최상단에 **종합 AI 적합도 (`CareFit Score`)** 단일 배지를 시각적으로 거대 강조한다.
- 복잡한 3개 AI 개별 추천 사유 및 심평원 실측 교차검증 내역은 기본적으로 숨겨두고, **`[AI 추천 근거 상세 보기 ▼]` 아코디언 토글**을 누를 때만 부드럽게 펼쳐지도록 구현하여 인지적 부하를 최소화했다.

### 2. B2B 요양기관 대시보드 (LUVIS 행동 유도형 뷰)
- 기관회원에게 자사 병원 vs 지역 경쟁 상위 10% 평균을 5개 축으로 비교하는 **AI 노출 가시성 방사형 레이더 차트(Radar Chart)**를 제공하여 개선 필요성을 직관적으로 전달한다.
- 차트 하단에 **원스톱 액션 솔루션 패널**을 장착:
  - `MedicalClinic JSON-LD 원클릭 복사`
  - `심평원 장비 연동 바로가기`
  - `AEO 최적화 블로그 템플릿 복사`
  - 유료 솔루션 전환 및 가시성 개선 행동을 원클릭으로 유도한다.

## 7. 실패·대체 처리 매트릭스

| 상황 | 처리 메커니즘 |
| :--- | :--- |
