# ✅ 요양병원 찾기 도우미 구현

## 후속 고도화: 다빈도 키워드·심평원 뱃지·3대 AI 연계 (2026-09-11)

- **다빈도 키워드**: 보호자 핵심 문의 질환인 `치매/인지`, `욕창 치료`, `암요양` 인식 및 DB 근거 매칭을 추가했습니다. 간병(간병인/공동간병) 문의에 대해서는 심평원 미보유 자료임을 안내하고 직접 상담을 유도합니다.
- **신뢰성 뱃지**: 결과 카드에 심평원 `평가 등급(1등급 등)` 및 `총 병상 수` 뱃지를 시각화했습니다.
- **3대 AI 브릿지**: ChatGPT·Gemini·Perplexity 비교 리포트로 이어지는 브릿지 카드를 결과 하단에 배치하고, 클릭 시 메인 검색창으로 조건이 전달되어 AI 정밀추천으로 즉시 연동됩니다.

## 후속 수정: 내 근처 및 다종별 검색

아래 최초 구현의 요양병원 전용 제한은 해제했다. 현재 초기값은 **전체 종별**이며 초기화 시 모든 조건이 해제된다. 요양·종합병원·호스피스 등 종별/등록 분류와 재활·척추·투석 등 진료 자료 조건을 구분한다. 빠른 카테고리 버튼은 기존 종별·진료조건을 교체하고, 대화로 입력하는 “재활도 필요해”는 조건을 누적한다.

“내 근처” 요청 때만 브라우저 위치 권한을 요청한다. 좌표 범위로 후보 조회 후 직선거리로 반경 밖 후보를 제외하고 거리순 정렬한다. 기본 반경 10km, 선택 버튼 3/5/10/20km. 위치 실패·거부 시 지역을 직접 입력할 수 있다. 특정 지역 입력은 내 근처 모드를 해제한다. 좌표는 공개 병원 DB 범위 조회에만 사용하고 저장하지 않는다.

현재 후보 조회 상한은 2,000곳이며 초과 시 일부 조회임을 명시한다. 밀집 지역 전체의 최단거리 병원을 보장하지 않으므로 반경 또는 종별을 좁히도록 안내한다. 실제 기기 브라우저 권한 UI 검증은 미실행이며, 공개 용인시청 좌표를 주입한 거리 필터·정렬과 운영 DB 검색을 검증했다.

검사: `node scripts/test_care_chat.cjs` 조건 36건 및 위치 성공·거부·시간 초과·취소 4건, `node scripts/check_care_chat_db.mjs` 8가지 실제 DB 검색. 브라우저 위치 처리는 `src/services/careChatLocation.ts`에 분리했다. 실제 조회에서 용인 종합병원 4곳·호스피스 2곳·재활 자료 확인 2곳·척추 자료 확인 0곳, 시청 좌표 반경 10km 종합병원 5곳을 확인했다. 척추 자료 미확인은 실제 서비스 부재를 뜻하지 않는다.

## 필터 확장

기본 병원찾기 화면에 `척추·관절`, `정형외과`, `한방·추나` 특화 필터를 추가했다. 재활은 심평원 병원명·종별·진료·상세정보·물리/작업치료 자료를 우선 확인한 뒤 기관회원의 `has_rehab`와 관련 태그를 보완 자료로 사용한다. 전문진료·의료진 태그는 심평원 확인 여부와 기관 제공 여부를 섞어 단일 사실로 표시하지 않도록 기존 출처 표시 흐름을 유지한다.

## 구현 범위

`project_review_2026-09-09.md` 5장의 첫 버전 방향에 따라 대화형 요양병원 DB 검색을 구현했다. 홈·병원찾기·전원 화면의 오른쪽 아래에서 열고, 모바일에서는 화면 대부분을 사용하는 대화창으로 표시한다.

- 지역과 요양병원(종별 28) 검색. 용인시 전체, 개별 구, 구 제외를 지원한다.
- 투석·재활·중환자실 조건을 이어서 추가하고 해제한다. 조건 되돌리기, 초기화, 조회 재시도를 지원한다.
- 심평원 원천의 치료·장비·인력·중환자 병상 자료에서 필수조건을 확인한다. 재활 관련 자료는 특정 치료 제공을 보장하지 않는다.
- 최신 DB에서 요양기호와 국내 좌표·주소를 검사하고, 확인되는 휴·폐업 상태를 제외한다. 운영상태 레코드가 없으면 추가 확인 필요로 표시한다.
- 가나다순 병원 카드, 상세 링크, 전화, 최대 3곳 비교와 상담 확인사항을 제공한다.
- DB 오류는 무결과와 구분한다. 지역 내 최대 2,000곳 검사 시 제한 사실을 안내하고 자동 지역 확대를 하지 않는다.
- 원문은 입력 처리에만 사용하고 대화에는 표준 조건만 남긴다. localStorage·외부 AI·검색 원장에 원문을 저장하거나 전송하지 않는다. 계정 또는 역할 변경 시 컴포넌트를 초기화한다.

## 아직 연결하지 않은 기능

이번 버전은 규칙 기반 대화형 검색이다. 검토 문서의 전체 AI 파이프라인을 완성했다는 의미가 아니다. `search_knowledge_base` 조건 캐시·벡터 유사 질문 재사용·단일 AI 설명 생성은 후속 구현 범위다. 의료 판단, 실시간 빈 병상, 실제 비용을 생성하지 않는다. 요양원·다른 기관 종류는 기존 병원찾기를 안내한다.

자유로운 모든 문장을 이해하지는 않는다. 모르는 요청에는 지역·서비스를 다시 묻는다. 원천 자료가 없거나 운영상태가 누락된 병원의 실제 서비스·영업 여부는 기관 확인이 필요하다.

## 결과 카드와 정렬

질문 원문은 현재 대화창에 사용자 말풍선으로 표시한다. 결과 카드에는 병원명, 심평원 종별, 질문 적합도 근거, 위치 거리, 주소, 승인 기관회원의 `상담 가능` 표시, 핵심 특화 태그와 상세·전화 동작만 남겼다. 기본 추천순은 `상담 가능 기관 → 질문 적합도 → 거리 → 병원명`이며, 사용자가 질문 적합도순 또는 거리순을 선택할 수 있다. 기관회원 승인 여부는 `get_active_hospital_ykihos` 공개 RPC를 사용하고, 프로필 조회가 실패하면 상담 배지를 표시하지 않은 채 심평원 결과는 계속 보여준다.
