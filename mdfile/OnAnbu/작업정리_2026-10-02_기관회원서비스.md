## 2. 기관회원 대시보드

### 2.1 신뢰 보완
- 숨겨져 있던 고정값 레이더 차트(재활 85점·투석 62점 등 모든 병원 동일)와 죽은 코드를 삭제했다.
- 담당자 연락처·사업자번호가 비면 실제 번호 대신 `000-0000-0000`, `000-00-00000`으로 표시한다.
- 근거 없는 "AI 노출 2.5배" 문구, 실제 등급이 없는 "정회원" 뱃지를 정리했다.
- 병원소식 샘플 4건의 실존 병원명(분당보바스기념병원 등)을 `온안부요양병원(개발테스트)`로 바꿨다.
- 키워드 집계 버그: ICU 키 오타, 그리고 검색 의도 저장 형식이 바뀌어 질환·인프라 키워드가 전혀 집계되지 않던 문제를 고쳤다.

### 2.2 지역 AI 검색 차트 (`지역 기반 AI 검색통계` 탭)
1. 최근 30일 지역 AI 검색 중 우리 병원 추천(누적 막대·마우스 툴팁·표 보기)
2. 우리 병원 추천 순위 분포(1위·2위·3위·4~5위·6위 이하)
3. 검색 조건별 노출률(혈액투석·재활·ICU·호스피스·조건 없음)
4. 지역 AI 추천 점유율 상위 기관(우리 병원 녹색 강조)

### 2.3 AI 가시성 리포트 (`AI 가시성 리포트` 탭, 무료)
- **AI 추천 경쟁력 5각형**(맨 위): 우리 병원(녹색) vs 지역 추천 상위 5곳 평균(회색 점선)

| 축 | 계산 기준(0~100) |
|---|---|
| 노출도 | 최근 30일 지역 AI 검색 추천 횟수, 지역 최다 추천 기관 = 100 |
| 순위력 | 추천 시 평균 순위(1위 100 · 2위 80 · 3위 60 · 4위 40 · 5위 이하 20) |
| AI 합의도 | 추천된 검색에서 응답한 AI(현재 Gemini·Perplexity) 중 우리 병원을 꼽은 비율 |
| 조건 적합도 | 질문을 7대 테마로 분류, 우리 병원이 가장 강한 테마 질문에서의 추천률 |
| 근거 충실도 | 홈페이지·전화·소개글·태그 3개↑·승인 태그·특화 인프라·기관회원 승인·인증 후기·홈페이지 진단·소식 등록 10개 항목 충족률 |

  - 표본이 적은 축은 "데이터 부족"으로 표시하고, 실제 사용자 검색이 10건 미만이면 벤치마크 결과로 자동 전환(토글 제공)한다.
  - 근거 충실도 미충족 항목을 체크리스트로 보여 준다.
- 점수 3종: ① AI 언급(노출률·지역 순위) ② AEO/GEO(구조화 데이터+신뢰 콘텐츠) ③ Trust(AI 크롤러 접근+기술 가독성)
- 마케팅 포인트(외부 AI 호출 없음, 비용 0원): 먼저 보완 / 성장 기회 / 홍보 강점, 모든 항목에 근거 수치 표시. 5각형의 가장 약한 축이 "먼저 보완"으로 연결된다.
- LUVIS 마케팅 상담 신청: 개인정보 제3자 제공 동의 후 병원명·담당자명·이메일·전화번호·마케팅 포인트 요약을 보관하고 최고관리자에게 알린다. 같은 기관은 24시간에 1회.

### 2.4 기관회원 카드 강조 (병원찾기)
- 승인 기관회원 카드: 상단 리본 "온안부 인증 기관 · 상담 요청에 병원이 직접 답변합니다", 녹색 테두리·그림자, 병원명 옆 반짝이는 "인증 기관 · 직접 상담" 배지(WCAG AA, 움직임 줄이기 시 반짝임 끔).

## 3. 알림 (앱 출시 없이 무료)
- 대상: 새 상담 요청·보호자 답변·취소 → 기관 담당자 / 병원 답변·추가 질문 → 보호자 / LUVIS 상담 신청 → 최고관리자
- 화면: 상단 알림 벨(실시간 배지·탭 제목 표시·모두 읽음), `브라우저 알림 켜기`(PC·안드로이드 바로, 아이폰은 홈 화면 추가 후)
- 발송: `notification_events` → DB 트리거(pg_net) → `notify-dispatch` Edge 함수 → 웹 푸시(VAPID), 푸시를 못 받은 사람에게만 이메일(Resend, 키 설정 시). 실패 건은 5분마다 재시도.
- 알림 문구에 환자 정보는 넣지 않는다.

## 4. 검색
### 4.1 병원 키워드 단순 검색
- `hosapi_hospital.verified_search_terms`(심평원 ETL과 분리된 검색 색인)에 기관 등록 태그·인프라, 관리자 승인 크롤링 태그, 심평원 호스피스 지정만 넣는다(검토 대기 태그 제외).
- 동의어 표 `search_term_synonyms`(예: 도수·물리치료 → 도수치료, 교통사고 → 자보). 기관 프로필이 바뀌면 자동 갱신.
- 결과 카드에 "🔤 검색어 일치 근거"(태그·출처)를 표시한다.

### 4.2 키워드 검색 기록·통계
- 실제 사용자 키워드 검색과 결과 카드 클릭을 `keyword_search_logs`·`keyword_search_clicks`에 USER로 기록(순위는 서버 계산, 7자리 이상 숫자 제거).
- 관리자 시뮬레이션은 BENCHMARK로 분리해 기관 대시보드·사이트 공개 "카드 조회" 수치에 섞이지 않는다.

### 4.3 AI 답변 표시
- 한 줄로 이어지던 AI 답변을 1위·2위·3위별로 줄을 나누고, `**강조**`를 굵게, 링크 없는 각주 `[3][4]`를 지운다.

## 6. 실행 결과 요약 (용인 수지·기흥·처인구)
### 6.1 AI 벤치마크 (Gemini·Perplexity, 210문항)
- 210문항 처리 완료, Perplexity 실패 54문항은 순차 재실행 후 3건만 실패로 남음. 이전 중복 기록 58건은 `BENCHMARK_SUPERSEDED`로 통계 제외.
- 구별 AI 추천 1위: 기흥 용인세브란스병원(27회) · 수지 용인수지병원(25회) · 처인 용인서울요양병원(20회). 1위 기관들도 근거 충실도 10~30점.
- 예시: 흥덕우리요양병원 5각형 70/64/71/100/50(지역 상위 평균 69/69/74/71/34), 암 요양 질문 9건 중 9건 추천.
- 온안부요양병원(개발테스트)은 실존하지 않아 실제 AI 추천 0건(팩트 검증 정상).

### 6.2 키워드 검색 시뮬레이션 (168건, 1~3위 클릭 259건)
- 0건 결과 29%(정신건강 88%·소아 50%), 클릭의 53%가 검색한 구 밖 병원(구 안 결과가 없으면 경기도·전국으로 확장).
- 키워드 상위 3곳 중 AI도 추천한 비율 11~50%.
- 개발 테스트 병원이 키워드 1위에 17회 노출 → 공개 검색 노출 여부 결정 필요.

## 7. 운영 버그 수정 (실제 사용자에게 영향)
1. AI 검색 지역 비교: '용인시 수지구'와 심평원 '용인수지구' 표기 차이로 시+구 지역의 AI 추천이 전부 탈락하던 문제.
2. Gemini 모델 종료: `gemini-2.0-flash` 등 종료 모델 → 실패 시 `gemini-3.8-flash`로 자동 대체(생각 수준 low).
3. Perplexity 응답 해석: 문자열 밖 출처 표시·중복 병원·답변 속 추천 목록 때문에 응답 전체가 버려지던 문제.
4. 관리자 차트 집계가 병원 지정 시에도 전국 기준이던 문제.
5. 수집 태그 검토가 500건에서 잘리던 문제(실제 3,410건 · 1,211곳).
6. 기관회원·관리자 상단 메뉴가 넓은 화면에서 잘리던 문제.

## 8. 크롤러 (야간 배치 = 개별 수집 같은 로직)
### 8.1 차이가 났던 이유
| 상황 | 이전 야간 배치 | 개별 수집(웹) |
|---|---|---|
| 수집 주소 | 심평원 주소만 | 관리자 확정·후보·심평원·프로필 주소 |
| 주소 없음 | 건너뜀 | 검색으로 홈페이지·블로그 발굴 |
| 접속 실패 | 실패 | 재검색 후 새 주소로 재시도 |
| 블로그 주소 | 블로그 껍데기만 읽음 | 공식 홈페이지 탐색 또는 블로그 본문 |

용인 기흥구 대상 26곳 중 14곳은 심평원 홈페이지 주소가 비어 있어 이전 배치가 통째로 건너뛰었다.

### 8.2 바뀐 점
- `resolve_crawl_url`: 웹 화면과 같은 우선순위(크롤러 후보[반려 제외·최신] > 심평원[블로그·플랫폼 제외] > 기관 프로필, 관리자 확정 주소 우선)로 수집 주소를 고른다.
- 야간 배치(EXE)와 웹 일괄 수집(로컬 서버)이 모두 `crawl_single_hospital`(개별 수집과 같은 함수)을 쓴다.
- 새 옵션 `--no-discover`: 검색 발굴 없이 빠르게 돌릴 때(기본은 발굴 켬).
- 웹 화면도 반려된 후보 주소를 수집에 쓰지 않고, 후보가 여러 개면 최신을 쓴다.
- 검색 단계가 늘어 배치 시간이 이전보다 길어질 수 있다.
- `수집 태그 검토`의 `검토 대기 병원만 보기`는 지역·종별 필터와 무관하게 대기 병원 전체를 불러온다.
