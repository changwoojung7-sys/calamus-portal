# 온안부 사용자 역할별 가입 및 운영 매뉴얼

> 기준일: 2026-09-29
> 대상: 개인회원(환자·보호자), 기관회원(요양기관 담당자), 최고관리자
> 주의: 이 문서는 현재 코드와 migration 기준이다. 신규 DB 기능은 해당 migration을 운영 Supabase에 적용한 뒤 사용할 수 있다.

## 1. 공통 서비스 구조

온안부는 의료기관의 입원 가능 여부를 대신 확정하는 서비스가 아니다. 사용자가 필요한 의료·돌봄 조건을 정리하고, 심평원 팩트·기관 확인 정보·후기·AI 검색 보조정보를 기관별로 확인한 뒤 상담으로 연결하는 서비스다. 병원 간 우열·순위·점수·나란히 비교는 제공하지 않는다.

공통 상단 메뉴는 다음과 같다.

| 메뉴 | 용도 |
| --- | --- |
| 홈 | 3가지 케어 가이드, 요양 경로 네비게이터, 비용 계산기와 이용 순서 확인 |
| 병원찾기 | 지역·병원 유형(복수 선택 지원)·시설 필터와 문장형 조건 검색으로 기관별 확인 정보 조회 |
| 상급병원 | 퇴원 기준병원과 반경을 선택하고 배후 요양·재활·정형(병원·의원)·한방·호스피스 기관 탐색 |
| 입원후기 | 병원별 이용자 후기 조회·작성, 후기 인증 상태 확인 |
| 병원소식 | 기관이 등록한 소식 확인 |
| 공지사항 | 서비스 변경·운영 안내 확인 |

## 2. 개인회원 매뉴얼

### 2.1 가입과 로그인

#### 소셜 간편가입

1. 우측 상단 `로그인·회원가입`을 누른다.
2. `개인회원(보호자)` 탭에서 카카오·네이버·Google 중 하나를 선택한다.
3. 최초 가입 전 필수 이용약관·개인정보 수집 이용 동의를 확인한다.
4. 서비스 소식 수신은 선택 동의이며 가입 조건이 아니다.
5. `동의하고 계속`을 누르고 해당 소셜 계정 인증을 마친다.
6. 기존 가입자는 새 회원을 만들지 않고 기존 계정으로 로그인된다.

#### 이메일 가입

1. `이메일 회원가입`을 선택한다.
2. 이름, 이메일, 8자 이상 비밀번호와 비밀번호 확인을 입력한다.
3. 서비스 이용약관과 개인정보 수집·이용에 필수 동의한다.
4. 회원가입 후 이메일 인증 링크를 연다.
5. 인증 완료 후 같은 이메일과 비밀번호로 로그인한다.

### 2.2 홈 화면 사용

1. 히어로 영역의 `검증 병원 바로 찾기` 또는 `퇴원·전원 설계하기`를 선택한다.
2. 바로 아래 3개 가이드에서 상황에 맞는 내용을 먼저 읽는다.
   - 요양병원과 요양원 선택 기준
   - 상급병원 퇴원 전 준비 순서
   - 호스피스·완화의료 상담 준비
3. `3단계 요양 경로 네비게이터`에서 의료처치 필요도, 장기요양등급, 필요한 시설 조건과 지역을 선택한다. 7대 테마 원클릭(시니어·암·정형재활·소아발달·정신건강·산부인과·호스피스)을 누르면 병원찾기와 같은 테마 검색 조건이 자동으로 채워진다.
4. `조건으로 병원 찾기`를 누르면 선택 지역과 의료·시설 조건이 병원찾기 필터로 전달된다.
5. 로그인 회원은 동의 후 조건을 저장해 다시 확인할 수 있다.
6. 네비게이터 바로 아래의 `상급병원 퇴원 후 전원 조건 준비`를 펼쳐 퇴원 일정, 병원 유형(`[병원·의원(정형·외과)]` 포함 복수 선택 가능), 의료·시설, 간병, 셔틀 조건을 미리 선택할 수 있다.
7. `이 조건으로 배후시설 찾기`를 누르면 선택값을 유지한 채 상급병원 퇴원기준 탭으로 이동한다. 기준 상급병원과 반경, 상담 후보 병원은 이동한 화면에서 선택한다.
8. 하단의 `예상비용 계산하기`에서 요양원·요양병원 예상 본인부담금 계산기를 연다. 재활·호스피스 정보는 상단 3개 선택 가이드에서 확인한다.

### 2.3 병원찾기와 AI 정밀검색

> 2026-10-15부터 병원찾기 조건은 **기관 구분**(심평원 종별: 요양병원·상급/종합·병원·의원·한방병원·한의원·호스피스 등)과 **진료분야**(재활·암·정형척추·소아·정신건강·산부인과·이비인후과·피부과·성형외과·안과·비뇨의학과) 두 줄로 고른다. 줄 안에서는 하나만 맞아도 되고, 두 줄은 모두 맞아야 한다. 진료분야를 고르면 그 분야의 세부 필터가 나온다. 맞춤 테마를 누르면 기관 구분과 진료분야만 자동으로 골라지고 필터는 직접 고른다. 홈 화면 '맞춤 케어·의료기관 네비게이터'도 같은 3단계(기관 구분 → 진료분야 → 꼭 필요한 조건)다.

#### 일반 검색

1. 검색 중심 지역을 시·도와 시·군·구로 선택한다. 시·군·구 목록은 심평원 DB 기준이며 구가 있는 시는 묶여 있고 '○○시 전체'도 고를 수 있다(예: 화성시 → 동탄·만세·병점·효행구).
2. 맞춤 테마를 고르면 그 테마에 맞는 병원구분과 근거 조건이 자동 적용된다. 상단 병원구분 칩은 **복수 선택(다중 토글)** 할 수 있다.
3. 입원병상·투석·재활·척추관절·ICU·교통사고·자동차보험 등 특화 조건을 고른다. 조건을 더 고르면 '이 중 하나라도 해당'(OR)이라 결과가 줄지 않는다. (호스피스 선택 시 입원형/가정형/자문형 세부 칩 연동)
4. 건수는 '근거 일치 N곳 / 후보 M곳 중'으로 표시된다. 후보가 2,000곳을 넘으면 검색 중심 위치에서 가까운 기관부터 확인한다.
5. 결과 카드의 **'🔎 검색 조건 일치 근거'**에서 조건별 근거와 출처(심평원 / 기관·관리자 등록 / 홈페이지 확인(관리자 승인))를 확인한다.
6. 암 요양 테마는 근거가 확인된 기관만 보인다. 0건이면 안내의 [근거 미확인 요양·한방병원까지 보기]로 넓혀 볼 수 있다(입원 전 병원 확인 필요).
7. 검색창에 '교통사고'(지역과 함께 예: '기흥구 교통사고')를 입력하면 교통사고·자동차보험 진료 근거가 있는 병원·의원·한방병원만 찾는다.
8. `40개 더 펼치기`를 누르면 다음 결과가 지도와 목록에 함께 추가된다(같은 검색은 항상 같은 순서·결과).

#### AI 정밀검색

1. 환자 실명·주민등록번호·전화번호를 제외하고 상태를 입력한다.
   - 예: `용인시, 78세 뇌경색 퇴원 예정, 보행 재활과 혈액투석이 모두 필요해요.`
2. AI 검색을 실행한다. (비회원 1회 무료 체험 지원, 2회째부터 로그인 유도)
3. 지도와 기관명순·거리순 목록에서 질문 조건에 해당하는 기관을 확인한다.
4. 기관 카드에서 해당 기관의 확인 정보, 출처, 미확인 항목을 살펴본다. 병원 간 종합점수·순위·우열은 표시하지 않는다.
5. AI는 질문에서 검색 조건을 정리하는 보조 수단이며 의료기관의 품질이나 치료 결과를 평가하지 않는다.
6. 실제 입원 가능일·진료 일정·비용은 해당 기관에 다시 확인한다.

### 2.4 상급병원 퇴원·전원 상담

1. 메인 전원 조건 준비에서 `이 조건으로 배후시설 찾기`를 누르거나, `상급병원` 메뉴로 직접 이동한다. 메인에서 정한 조건이 있으면 그대로 유지된다.
2. 현재 입원 중이거나 퇴원할 기준병원을 선택한다.
3. 반경 5km·10km·15km 중 하나를 선택한다.
4. 기본으로 접혀 있는 `전원설계 펼치기`를 누른다. 접힌 상태에서도 현재 기준병원·반경·상담 요청 기관 수를 확인할 수 있다.
5. 병원 유형(`[전체 시설]`, `[요양병원]`, `[재활병원]`, `[병원·의원(정형·외과)]`, `[한방병원·한의원]`, `[호스피스]`)을 **자유롭게 복수 선택(다중 토글)**하여 필요한 배후 기관 유형들을 동시에 조회하고, 간병 형태와 셔틀 필요 여부를 설정한다.
6. 후보 병원 카드나 병원찾기·챗봇에서 상담할 기관 1~3곳을 `상담 요청 기관`으로 선택한다.
7. 화면 하단 `입원상담 작성`을 누르면 상급병원 화면의 상담 설계 영역으로 이동하면서 3단계 작성창이 열린다. 비회원 또는 화면에 이름만 남은 상태면 실제 이메일·소셜 로그인을 완료한다.
8. **점진적 3단계 선택형 작성 (수기입력 최소화)**:
   - **1단계: 테마·상담 목적·선호 조건**: 7대 테마와 테마 안의 상담 목적(예: 산부인과 → 분만/산후 회복/난임, 호스피스 → 입원형/가정형/자문형), 희망 입원 시기, 선호 병실, 간병 형태, (장기 입원 테마만) 월 예산을 칩으로 선택.
   - **2단계: 환자 상태**: 테마별 연령(시니어 70~90대 / 소아 영유아·아동·청소년 / 산부인과 35세 기준), 테마가 묻는 경우의 거동·식사, 테마별 상태(예: 고위험 산모, 돌발통증, 말기 진단), 필요한 처치, 특화 조건·특이사항 칩을 선택.
   - **3단계: 안심 연락처**: 보호자 성명과 전화번호, 통화 편한 시간대를 선택하고 필수 동의 후 요청 전송. 회신 시간은 기관 운영 상황에 따라 다르다.
9. 개인정보와 상담 내용 전달 범위를 확인하고 동의한 뒤 `N곳에 상담 요청`을 누른다.
10. 로그인 후 상단 메뉴 **`내 입원상담`**(2026-10-16 추가, 새 답변이 있으면 '새 답변 N' 표시)에서 기관별 검토 상태, 가능 시점, 비용 범위, 미확인 항목과 답변 유효기간을 각각 확인한다. 홈 화면과 내 정보 창의 요약에서도 '전체 화면으로 보기'로 들어갈 수 있다. 기관 답변은 나란히 비교하지 않는다.
11. **상담 문답 및 취소**: 병원이 추가정보를 요청하면 병원별 문답에서 필요한 내용만 답한다. 필요한 경우 개별 병원 건별로 상담 요청을 즉시 취소할 수 있다.
12. 환자 실명, 주민등록번호, 상세 주소, 진료기록 원본은 입력하지 않는다. 병원이 추가 서류를 요구하면 통화 후 안전한 별도 경로를 확인한다.

### 2.5 예상 비용 계산기

1. 홈 하단 `예상비용 계산하기`를 연다.
2. 요양원 또는 요양병원을 구분해 선택한다.
3. 급여 총액, 식사재료비, 간병비, 상급병실료와 기타 비급여를 실제 안내받은 금액으로 입력한다.
4. 계산 결과는 예상치이며 기관 청구서와 공단 적용 결과를 우선한다.
5. 회원이 별도 동의한 계산만 계정에 저장된다.
6. 팝업은 닫기 버튼을 눌러야 닫히며, 열려 있는 동안 배경 화면을 조작할 수 없다.

### 2.6 입원후기

1. `입원후기`에서 병원을 선택하고 작성자 표시명, 환자와의 관계, 항목별 점수와 경험을 작성한다.
2. 신규 후기는 즉시 `미인증`으로 공개된다.
3. 인증 배지가 없는 후기는 개인 경험으로 참고한다.
4. 현재 서비스는 영수증·진단서 파일을 후기 화면에 업로드받지 않는다.
5. 관리자에게 인증 요청은 가능하지만, 기관 확인 등 감사 가능한 근거가 확보되지 않으면 인증 승인할 수 없다.

### 2.7 FAQ와 약관 확인

1. 상단 메뉴의 `FAQ`를 누르면 일반사용자·기관회원·개인정보 항목별 안내를 검색할 수 있다. 홈 화면 추가, 알림, 입원상담, 기관 검색 키워드와 개인정보는 자주 찾는 도움말 버튼으로 바로 볼 수 있다.
2. 하단 `이용약관`과 `개인정보처리방침`은 가입창을 열지 않고 바로 확인할 수 있다.
3. 계정 탈퇴, 개인정보 열람·삭제 또는 기관회원 승인 문의는 하단 고객센터 이메일로 접수한다. 주민등록번호나 진료기록 원본은 이메일에 첨부하지 않는다.

### 2.7-1 휴대폰 홈 화면 바로가기와 알림

1. 온안부는 별도 iOS·Android 앱을 출시하지 않는다. 아이폰은 Safari 공유 버튼 → `홈 화면에 추가`, 안드로이드는 Chrome 메뉴 → `홈 화면에 추가`를 선택한다. 브라우저에 따라 이 기능이 `앱 설치`로 표시될 수 있지만 앱스토어에서 받는 별도 앱이 아니라 현재 웹사이트의 바로가기다.
2. 홈 화면의 온안부 아이콘으로 열고 로그인한 뒤 상단 종 모양 알림 버튼에서 `브라우저 알림 켜기`를 누른다.
3. 휴대폰이 묻는 알림 권한을 허용해야 병원 답변과 추가정보 요청을 웹 푸시로 받을 수 있다. 바로가기만 만든 상태에서는 알림이 자동으로 켜지지 않는다.
4. 알림을 지원하지 않거나 차단한 브라우저에서도 로그인 후 상단 알림함으로 상담 소식을 확인할 수 있다.

### 2.8 비공개 문의하기

1. 상단 `문의하기`로 이동하고 로그인한다.
2. 일반회원 또는 기관회원 작성자 유형은 로그인한 계정 권한과 일치해야 한다.
3. 문의 유형, 제목, 질문과 답변 알림 연락정보를 입력한다. 주민등록번호나 진료기록 원문은 적지 않는다.
4. 영문과 숫자를 포함한 6자 이상의 글 비밀번호를 설정한다. 서버에는 원문이 아닌 복구 불가능한 해시만 저장된다.
5. `내 문의`에서 글을 선택한 뒤 글 비밀번호를 입력해야 질문, 연락정보와 관리자 답변을 볼 수 있다.
6. 비밀번호를 5회 연속 틀리면 10분 동안 잠긴다. 관리자는 문의 처리 목적으로 전체 글을 볼 수 있다.

## 3. 기관회원 매뉴얼

### 3.1 최초 가입 신청

1. 로그인 창에서 `기관회원(이메일 인증)`을 선택한다.
2. 지역과 의료기관을 검색해 심평원 요양기호가 일치하는 기관을 선택한다.
3. 담당자 성명·직책·연락처, 사업자등록번호와 업무 이메일을 입력한다.
4. 서비스 이용약관과 개인정보 수집·이용에 동의한다.
5. 이메일로 받은 6자리 인증번호를 제한시간 안에 입력하고 비밀번호를 설정한다.
6. 이메일 인증 완료는 기관 소유권 승인을 의미하지 않는다. 최고관리자의 기관·담당자 검토를 기다린다.
7. 승인 후 기관회원 계정으로 다시 로그인하면 B2B 대시보드와 기관 정보 관리 기능을 사용할 수 있다.

### 3.2 B2B 대시보드

1. 상단 `B2B 대시보드`를 연다.
2. 승인된 요양기호와 기관명이 맞는지 확인한다.
3. AI 검색 노출·병원 상세 조회·후기·AI 가시성 진단 현황을 확인한다.
4. 공식 홈페이지가 등록된 경우 `AI 가시성 진단`을 실행할 수 있다.
5. 통계가 0이면 임의 예시 수치로 대체하지 않고 0으로 표시된다.
6. `지역 기반 AI 검색통계` 탭에서 최근 30일 지역 검색 중 우리 병원이 확인된 횟수와 검색 조건별 노출률을 본다. 다른 기관의 실명·순위·점유율은 제공하지 않는다.
7. `AI 가시성 리포트` 탭에서 ① 우리 기관 검색 노출 ② AEO/GEO(구조화 데이터·신뢰 콘텐츠) ③ Trust(AI 크롤러 접근·기술 가독성)를 확인하고, 자기 기관 홈페이지의 보완 항목과 홍보 가능한 사실을 확인한다.
8. 전문 상담이 필요하면 `LUVIS 마케팅 상담 신청`을 누르고, 전달 항목(병원명·담당자명·이메일·전화번호·마케팅 포인트 요약)을 확인한 뒤 개인정보 제3자 제공에 동의한다. 같은 기관은 24시간에 한 번만 접수된다.

### 3.2-1 알림 받기

1. 로그인 후 상단 종 모양 아이콘을 누른다. 읽지 않은 알림 수가 배지와 브라우저 탭 제목에 표시된다.
2. `브라우저 알림 켜기`를 누르고 브라우저 권한을 허용하면 온안부를 닫아 두어도 새 상담 요청·보호자 답변·취소 알림이 온다(무료).
3. 아이폰은 Safari 공유 버튼 → `홈 화면에 추가`로 설치한 뒤에만 알림을 켤 수 있다.
4. 알림에는 환자 정보가 없으며, 알림을 누르면 B2B 대시보드로 이동한다. 대시보드를 열어 둔 상태면 상담 목록이 자동으로 새로 고쳐진다.
5. 보호자(개인회원)도 같은 방법으로 병원 답변·추가 질문 알림을 받는다.

### 3.3 기관 정보 관리

1. `병원 정보 / 비급여 스튜디오 관리`를 연다.
2. 공식 홈페이지, 예약·입원상담 전화, 블로그·유튜브, 소개, 특화 진료, 병상·간병·셔틀·비급여 정보를 입력한다.
3. **호스피스 완화의료 전용 관리 (`🕊️ 3. 호스피스 완화의료` 탭)**:
   - 보건복지부 지정 기관인 경우 입원형, 가정형, 자문형 호스피스 제공 여부를 스위치로 활성화한다.
   - 인가 병상수(예: 15병상)와 간병보조인력(전담 간병도우미 제도) 운영 여부를 체크한다.
   - 최초 지정일자, 소아청소년 완화의료 참여 여부, 대상질환(말기암, 만성간경화 등)을 관리한다.
   - 입력된 호스피스 정보는 심평원 공공데이터 정기 업데이트 시에도 유실되지 않는 기관 전용 프로필(`hospital_provider_profiles`)에 영구 저장된다.
4. 심평원 원천 팩트와 충돌하는 정보는 기관 홍보 문구만으로 변경되지 않는다.
5. 환자에게 공개되는 항목은 최신 운영 상태와 일치하도록 정기적으로 갱신한다.

### 3.4 전원 상담 요청 처리

1. B2B 대시보드 `전원 상담 요청`에서 새 요청을 확인한다.
2. **보호자 의뢰 스플릿 요약 확인**: 상단에 요약된 보호자 의뢰 내용(입원 희망 시기, 병실 선호, 간병 형태, 필요 처치, 메모)을 한눈에 파악한다.
3. 기준 상급병원, 거리, 퇴원 예정, 의료 필터, 간병·셔틀 조건을 확인한다.
4. 실제 검토 결과에 따라 `추가정보 필요`, `조건부 검토 가능`, `현재 수용 어려움`을 선택한다. `수용 어려움`은 사유 칩 5종 중 하나를 반드시 고르며(병상·입원일·대기일은 자동 정리), `대기 병상`은 예상 대기일(1일 이상)을 입력해야 저장된다.
5. 병상 상태, 가능한 날짜(오늘/내일/3일 뒤 퀵 버튼 제공), 예상 대기일, 필요서류(의사소견서, 투약기록지 칩 토글), 담당 연락처와 답변 유효기간을 입력한다.
6. **원클릭 표준 견적 프리셋 활용**: 의뢰 테마(7대)에 맞는 견적 프리셋 버튼을 눌러 비용 항목과 산정 기준, 포함/제외 항목을 자동 완성한 뒤 기관의 실제 금액으로 조정한다. 상단에 의뢰 테마와 상담 목적이 표시된다.
7. **상용구 템플릿 활용**: `[입원 가능(병상 확보)]`, `[서류 검토 후 확정]`, `[단기 대기 접수]` 버튼을 눌러 정중한 안내 문구를 즉시 삽입한다.
8. 정보가 부족하면 주민등록번호나 진료기록 원본을 요구하지 말고 추가정보 문답으로 필요한 내용만 질문한다.
9. 비용 수정은 이전 견적을 덮어쓰지 않고 새 버전으로 남긴다.
10. 연락처와 건강 관련 요약은 해당 상담 목적으로만 사용하고 개인 메신저·개인 파일에 복사하지 않는다.
11. `조건부 검토 가능`은 입원 확정이 아니다. 의료진 검토, 서류 확인, 병상과 비용 안내를 별도로 완료한다.

### 3.5 후기와 담당자 변경

- 기관회원은 자기 기관의 후기 현황을 참고할 수 있지만, 자기 기관 후기를 직접 `실입원 인증`으로 승인할 수 없다.
- 담당자가 바뀌면 프로필의 담당자 인수인계를 사용한다. 기존 담당자 이메일 인증 또는 최고관리자 검토를 거쳐 계정·연락처를 변경한다.

## 4. 최고관리자 매뉴얼

### 4.0 관리자 화면 (2026-10-03 통합)

상단 메뉴 `관리자`에서 아래 탭을 오간다(주소 `/admin?tab=...`).
- `기관회원 관리`: 가입 신청 승인·반려, 담당자 인수인계, 후기 인증 요청.
- `LUVIS 상담 신청`: 기관회원이 동의하고 보낸 마케팅 상담 신청(병원·담당자·연락처·신청 당시 마케팅 포인트와 근거)과 처리 상태. 신청 알림을 누르면 이 탭이 열린다.
- `의료기관별 대시보드`: 병원명을 검색해 고르면 해당 기관의 검색 확인 추이와 홈페이지 AEO/GEO·Trust 진단 및 보완 항목을 본다. 다른 기관과의 순위·우열·비교표는 제공하지 않는다.
- `병원정보관리(크롤링)`: 홈페이지 수집, 수집 태그 검토(검토 대기 병원만 보기·지역·급별·태그 키워드 필터), 야간 배치.
- `AI 통계·설정`: 지역 AI 검색 통계, AI 엔진 설정, AI 벤치마크, 키워드 검색 통계.
- `키워드 검색 통계`: AI 없이 키워드로 검색한 횟수·0건 비율·결과 카드 클릭·지역 밖 클릭을 시뮬레이션/실제 사용자로 나눠 본다. 개별 병원 클릭 순위와 AI 추천 일치율은 표시하지 않는다.
- `AI 벤치마크 배치 관리`: '용인 3개 구 7대 테마 210개' + '활성 AI 엔진'으로 실제 AI 검색과 같은 경로의 표본을 만든다. 배치는 한 번에 하나만 실행한다(Perplexity 요청 제한).
- 키워드 시뮬레이션은 `node scripts/run_keyword_benchmark.mjs`로 실행한다(AI 비용 없음).

### 4.0-1 일반회원 관리 (2026-10-16)

관리자 화면 → **일반회원 관리** 탭에서 일반회원의 가입일·가입 방식·이름·연령대·최근 로그인·입원상담 이용 현황을 본다. 이메일·휴대전화는 가려져 있고, 꼭 필요할 때만 **연락처 보기**를 누른다(누가 언제 봤는지 기록된다). CSV도 가린 값으로만 내려받는다. 회원 정보 수정·삭제는 이 화면에서 하지 않는다.

### 4.1 로그인과 권한

1. 관리자 전용 로그인으로 접속한다.
2. 관리자 계정은 일반 개인·기관 계정과 분리해 사용한다.
3. 관리자에게만 `기관회원관리`, `병원정보관리` 메뉴가 표시된다.

### 4.2 기관회원 승인

1. `기관회원관리`의 승인 대기 목록을 연다.
2. 선택 요양기호·기관명·사업자등록번호·업무 이메일·담당자 연락처의 일관성을 확인한다.
3. 기관 대표번호나 공식 채널을 통해 담당자 소속을 별도 확인한다.
4. 확인 근거를 관리자 메모에 남기고 승인한다.
5. 불일치 또는 확인 불가 시 사유를 작성해 반려한다.
6. 담당자 퇴사·변경 요청은 기존 계정과 새 담당자 정보를 대조한 뒤 처리한다.

### 4.3 후기 인증 요청

현재 관리자 화면만으로 영수증이나 진단서의 진위를 판별하는 것은 현실적으로 불가능하다. 따라서 다음 원칙을 적용한다.

1. 주민등록번호·진단서·영수증 이미지를 일반 후기 DB나 관리자 메모에 저장하지 않는다.
2. 단순 영수증 이미지 육안 확인만으로 승인하지 않는다.
3. 기관 담당부서 유선 확인, 안전한 오프라인 증빙 대조, 향후 공인 연동 데이터 확인처럼 감사 가능한 방법이 있을 때만 승인한다.
4. 승인·반려 모두 확인 방법·확인일 또는 구체 사유를 10자 이상 기록해야 한다.
5. 확인할 수 없으면 미인증 상태를 유지하거나 반려한다.
6. 향후 안전한 증빙 접수·보관기간·열람권한·파기정책이 구현되기 전에는 `100% 실입원 인증`을 홍보 문구로 사용하지 않는다.

### 4.4 병원 홈페이지 크롤링과 Trust 검증

**야간 배치와 자동 처리 (2026-10-16 현행 — 상세: `병원홈페이지 크롤링계획_EXE Plan.md`)**

- 받을 파일: '서울·경기 병원급 이상 전용 배치', '서울·경기 의원급 전용 배치', '지역별 배치 ZIP'. 모두 **최근 1일 안에 수집한 곳은 건너뛰므로**, 멈췄으면 같은 파일을 다시 실행하면 이어서 돈다. 수집에 실패한 곳은 매번 다시 시도한다.
- PC 절전 모드를 끄고 실행한다. 같은 PC에서 두 배치를 동시에 돌리지 않는다(다른 PC는 괜찮다).
- 한 병원이 3분을 넘으면 '시간 초과'로 기록하고 다음 병원으로 넘어간다.
- **공식 홈페이지 자동 확정**: 크롤러가 찾은 홈페이지에 기관명과 심평원 대표전화가 함께 있으면 바로 공식 홈페이지로 확정된다(병원 찾기 포털·공공·블로그·단축주소 제외). 관리자는 '홈페이지 후보'(자동 확인이 안 된 곳)와 '공공·플랫폼 의심'만 확인하면 된다.
- 홈페이지가 없어 건너뛴 곳·실패한 곳은 DB(`hospital_crawl_misses`)에 횟수와 함께 기록된다. 여러 번 '홈페이지 없음'인 곳은 `--skip-no-homepage 2` 옵션으로 수집 대상에서 뺄 수 있다.
- 키워드는 수집 단계에서 AI 검토 거절 유형(단어만·키워드 나열·주차장 규모 없음·직함 없는 전문의·다른 병원 경력·포털 문장)을 미리 거른다. 남은 검토 대기는 AI 검토 기록을 참고해 승인·거절한다. 승인하면 진료분야도 자동으로 다시 계산된다.

**대상 선택과 수집 (2026-10-01)**

1. `병원정보관리`에서 시·도와 **구·군(다중 선택, '○○시 전체' 묶음)**, 병원구분(요양병원·재활병원·한방병원·병원 등)을 고른다. 목록은 최대 3만 곳까지 모두 불러오며 표는 300행씩 펼친다(통계·일괄 크롤링은 전체 기준).
2. 웹에서 수집: [서버 실행기]를 켠 뒤 [수집완료 병원 제외] → [전체 대상 순차 크롤링]. 크롬이 '로컬 네트워크 액세스'를 물으면 허용한다.
3. 야간 배치: '최근 ○일 수집 병원 제외'(기본 7일)를 고르고 [야간 배치 파일]을 내려받아 실행한다. 다른 PC는 처음 한 번 **최고관리자 이메일·비밀번호로 로그인**하고 '로그인 유지(Y)'를 고르면 다음부터 자동 실행된다. 계정을 바꾸려면 `AnOnDoc_Crawler_Server.exe --cli --logout`. 같은 폴더에 예전 EXE가 있으면 지우고 실행한다.
4. 수집 결과는 운영 DB에 바로 저장되고, 사람이 보는 기록은 `mdfile/crawling_log/crawl_날짜.md`에 남는다('DB 저장 실패' 병원은 재수집).

**수집 태그 검토**

5. 목록 위 요약(대기 건수·병원 수)과 [검토 대기 병원만 보기]로 대상을 고른다.
6. 병원 행의 [태그 검토]에서 출처 문장을 확인하고 **체크박스로 일괄 승인**하거나 사유 칩으로 거절한다. 출처 문장이 없는 태그는 승인할 수 없다.
7. 승인한 태그만 검색·AI 근거가 되며 마지막 확인일로부터 180일 뒤 만료된다(재수집되면 연장). 잘못 승인한 태그는 [승인] 탭에서 **승인 취소(거절)** 하면 검색에서 즉시 빠진다. 거절·만료 내역도 탭에서 다시 볼 수 있다.
8. 소아재활·아동발달·암요양·인공관절·골절수술·교통사고 등 민감 태그는 명확한 단어가 있을 때만 수집된다. 기관 태그를 직접 추가·삭제하려면 병원명을 눌러 편집 창을 연다.

**공식 홈페이지 검증**

1. 지역·병원종별·병원명 조건으로 목록을 좁힌다.
2. URL 수작업 검증 필터로 `공공·플랫폼 의심`, `홈페이지 후보`, `후보 반려`, `블로그만 보유`, `수집 실패`, `채널 없음` 목록을 분리한다. 자동 발굴 URL은 공개 홈페이지에 바로 반영되지 않는다.
3. `홈페이지 후보`는 기관명·주소·대표/예약전화를 실제 사이트와 대조한 뒤 `[대조 후 확정]`하거나 `[반려]`하고 사유를 남긴다. 확정된 URL만 HIRA·기관 공개 프로필과 Trust 진단에 반영된다. (2026-10-16부터 기관명·대표전화가 자동 확인된 후보는 크롤링 때 자동 확정되므로, 이 목록에는 자동 확인이 안 된 곳만 남는다.)
4. 의심 원천 URL을 열어 병원명·대표전화·주소와 공식 소유관계를 확인한다. 공립병원·보건소처럼 정부 사이트가 실제 공식 홈페이지면 `[수동 확정]`, 아니면 주소를 지운다.
5. 구청·공공기관·의료 플랫폼·목록 페이지는 공식 홈페이지로 승인하지 않는다.
6. 크롤링은 예약전화·공식 채널·특화 태그 후보를 수집하는 도구이며, 웹 문구만으로 투석·ICU 등 심평원 hard filter를 변경하지 않는다.
7. Trust 배치는 검증된 공식 홈페이지에 대해서만 실행한다.

### 4.5 비용 기준 관리

1. 시행일, 종료일, 공식 출처 URL과 확인일을 함께 관리한다.
2. 새 부담률을 코드에 직접 고정하지 않고 `benefit_rate_versions`에 버전으로 추가한다.
3. 기존 계산 결과 재현을 위해 과거 버전을 삭제하지 않는다.
4. 본인부담상한제·간병 지원은 적용 조건을 확인하지 않은 채 자동 차감하지 않는다.

## 6. 개인정보 입력 금지와 허용 범위

- AI 검색창: 환자 실명·주민등록번호·연락처 입력 금지. 입력된 식별정보는 외부 모델 전송 전 마스킹한다.
- 전원 상담: 명시적 동의 후 보호자 성명·연락처와 직접 작성한 최소 환자 상태 요약만 선택 기관에 전달한다.
- 후기: 주민등록번호·진단서·영수증 파일을 입력하거나 첨부하지 않는다.
- 기관·관리자: 상담 정보와 후기 확인 기록을 업무 목적 밖으로 복사·재사용하지 않는다.

- `202609190001_private_inquiries_and_site_activity.sql`: 비공개 문의·비밀번호 해시·관리자 답변·방문/검색 집계 지원
