- '재활병원'·'산부인과'는 심평원 종별이 아니어서 기관 구분에서 빼고 진료분야로 옮겼다.

### 7대 테마 자동 선택 (일반검색 · 메인 네비게이터)

테마는 **기관 구분 + 진료분야만** 자동 선택하고, 필터는 자동 선택하지 않는다(대표 필터를 먼저 보여 주기만 한다). 입원병상 조건은 그대로 둔다.

| 테마 | 기관 구분 | 진료분야 | 순위 가산(선호) | 입원병상 |
|---|---|---|---|---|
| 시니어 | 요양병원, 정신병원 | — | 혈액투석 | ✓ |
| 암 | 요양병원, 병원, 의원, 한방병원, 한의원 | 암 | — | ✓ |
| 정형 | 병원, 의원, 한방병원, 한의원 | 정형·척추, 재활 | 전문재활 | ✓ |
| 소아 | 상급·종합, 병원, 의원, 정신병원 | 소아 | 전문재활 | — |
| 정신 | 정신병원 | 정신건강 | — | ✓ |
| 산부인과 | 상급·종합, 병원, 의원, 조산원 | 산부인과 | — | — |
| 호스피스 | 호스피스 | — | — | — |

- 암 테마가 0건이면 '근거 미확인 기관까지 보기'가 진료분야 '암'을 해제하고 순위 가산으로 바꾼다.
- 상급병원 퇴원연계(전원) 화면은 진료분야 줄이 없어 기존처럼 핵심 필터를 필수 근거로 건다. 입원상담 테마(`transferTheme`)는 화면 선택과 별도로 유지한다.
- 검증: `npm run test:theme-search`가 화면과 같은 방식(기관 구분 + 진료분야, 필터 자동 선택 없음)으로 7개 테마 × 4개 권역을 확인한다.

## 1. 역할 분리

| 영역 | 역할 | 검색 방식 |
|---|---|---|
| 상단 7개 테마 | 빠른 추천 프리셋. 기관 유형 + 핵심 필터 1개 + 입원병상을 한 번에 설정 | - |
| 기관 유형 (기관 구분 / 병원 유형) | 여러 개 선택 가능 | **OR** (하나라도 해당하면 포함) |
| 하단 대표 필터 | 사용자가 직접 조합하는 조건 | **AND** (선택한 조건을 모두 충족) |
| 필터 안의 키워드·별칭 | 수집 키워드 여러 개 → 대표 필터 1개 | **OR** (하나만 확인돼도 그 필터 충족) |

## 2. 화면 규칙

1. **전체 기관**을 고르면 기존 고정 필터 11개(아래 표의 ★)를 그대로 보여 준다. 이미 선택한 세부 필터가 있으면 숨기지 않고 함께 보여 준다.
2. 특정 기관 유형을 고르면 그 유형에 맞는 필터만 **소그룹**(치료·재활 / 수술 / 입원·돌봄 / 특화 진료 / 시설·장비 / 생활 지원)으로 보여 준다.
3. 테마를 적용한 상태면 그 테마의 대표 필터를 먼저 보여 주고, 나머지는 **필터 더보기**로 연다. 테마가 없으면 기본 필터(★)를 먼저 보여 준다.
4. 기관 유형을 바꿔 선택돼 있던 필터가 맞지 않게 되면 **자동 해제**하고 "현재 기관 유형과 맞지 않는 필터 N개(…)를 해제했습니다"라고 안내한다. 숨은 조건 때문에 결과가 줄어드는 일을 막기 위해서다.
5. 테마를 적용한 뒤 기관 유형·필터·입원병상을 직접 바꾸면 테마 버튼에 **테마 조정됨**을 표시한다. 같은 테마를 다시 누르거나 **선택 안 함**을 누르면 테마 조건이 모두 해제된다.
6. 맞춤 테마는 처음에 **선택 안 함** 상태다. 테마는 필수가 아니며, 사용자가 테마 없이 기관 유형·필터를 직접 고를 수 있다. 입원상담 접수에 쓰는 테마 값(`transferTheme`)은 화면 선택과 별도로 유지한다.
7. 서로 다른 의료행위는 한 필터로 묶지 않는다. 예: 도수치료·물리치료·작업치료, 로봇수술·로봇재활, 사랑니 발치·구강악안면외과.
8. 한방 진료(한방·추나, 추나치료)는 **한방병원·한의원**에서만 보여 준다. 양방 병원의 양한방 협진은 `양한방 협진` 필터로 따로 둔다.

## 2-1. 치과 전문 진료 필터

- 심평원 DB에는 치과병원(41)·치과의원(51)의 진료과목 정보가 비어 있다(2026-10-06 확인: 19,636곳 모두 빈 값). 그래서 치과 필터는 **홈페이지·의료진 프로필에서 수집하고 관리자가 승인한 태그**, 또는 활성 기관회원이 입력한 태그로만 판정한다.

## 4. 판정 근거와 우선순위

설정표 기반 세부 필터(아래 표에서 "기존 전용 판정"이 아닌 필터)는 다음 순서로 근거를 찾고, 처음 찾은 근거를 출처와 함께 카드에 표시한다.

1. 기관 체크항목(`hospital_provider_profiles`의 `has_*` 플래그) → 출처 "기관·관리자 등록"
2. 심평원 상세 수치: 물리치료실 병상, 물리치료사·작업치료사 인원 → "심평원"
3. 심평원 특수진료·장비·기관명·상세정보 키워드 → "심평원"
4. 관리자가 승인한 크롤링 태그(`verified_crawl_tags`) → "홈페이지 확인(관리자 승인)"
5. 활성(승인) 기관회원이 직접 입력한 태그 → "기관·관리자 등록". 비활성 기관의 입력 태그는 근거로 쓰지 않는다.

- 영문 약어(IVF·IUI·NICU·ESWT 등)는 다른 영단어 일부로 잡히지 않도록 단어 경계를 확인한다.
- 미검증 `crawled_tags`는 쓰지 않는다(팩트 그라운딩 원칙).
- 2026-10-06 현재 서울 강남·분당·기흥·해운대(약 3,700곳) 기준으로 산부인과 세부, 수술, 소아 세부 필터는 승인된 근거가 거의 없어 **0건**이다. 크롤링 승인이 쌓이면 결과가 늘어난다.
