# WorkNexus: 우리 회사 서버 한 대로 운영하는 독립형 3D 가상 오피스 제품소개서

## 1\. 디지털 전환 시대, 가상 오피스의 새로운 기준

디지털 전환이 가속화되면서 하이브리드 근무 환경은 이제 선택이 아닌 필수가 되었습니다. 그러나 대다수 기업이 도입한 기존 클라우드(SaaS) 기반 가상 오피스는 두 가지 치명적인 한계에 직면해 있습니다. 첫째, 기업 내부의 민감한 정보가 외부 서버에 보관되는 **데이터 보안의 불안정성**이며, 둘째, 매월 인원수와 비례하여 기하급수적으로 누적되는 **매몰 비용(Sunk Cost)의 부담**입니다.

\*\*워크넥서스(WorkNexus)\*\*는 이러한 한계를 완벽히 해결하는 '기업용 독립 사옥' 솔루션입니다. 외부 플랫폼을 임대하는 방식에서 벗어나, 우리 회사만의 서버에 직접 구축하는 온프레미스(On-Premise) 방식을 통해 보안과 경제성을 동시에 확보한 독보적인 비즈니스 공간을 제공합니다.

---

## 2\. 핵심 가치 제안: 지속 가능한 하이브리드 워크 구현

워크넥서스는 기업 경영진이 중시하는 경제적 가치를 극대화하기 위해 다음의 \*\*'3無 원칙'\*\*을 준수하며, 운영 효율성을 혁신합니다.

* **비용의 혁신:** **사내 완결형 온프레미스 인프라.** 값비싼 외부 SaaS 구독료 없이 우리 회사 서버 한 대만으로 대규모 가상 오피스를 안정적으로 운영할 수 있습니다.
* **무제한 확장성:** **데이터 유출 걱정 없이, 사내 인프라 중심** 기업의 성장에 맞춰 자유롭게 공간과 인원을 확장할 수 있어 장기적 관점의 인프라 투자 효율성이 탁월합니다.
* **3無 원칙 (워크넥서스 핵심 슬로건):**
  * **인당 월 구독료 없음:** 임직원 수가 늘어나도 추가 SaaS 구독료가 발생하지 않습니다.
  * **클라우드 비용 없음:** 자체 서버 운영으로 매월 지출되는 고정 인프라 비용을 절감합니다.
  * **데이터 외부 반출 없음:** 모든 소통 정보와 지적 자산이 사내망 내부에 존재하여 완벽한 \*\*데이터 주권(Data Sovereignty)\*\*을 확보합니다.

## 3\. 비주얼 정체성 및 사용자 경험 (Visual Identity &amp; UX)

워크넥서스는 친근한 디자인과 기술적 최적화를 통해 임직원의 몰입도와 소속감을 고취합니다.

* **친근한 시각 경험:** 로블록스(Roblox)와 마인크래프트(Minecraft) 스타일의 **픽셀 도트 및 복셀(Voxel) 기반 3D 아바타 디자인**을 채택하여, 디지털 워크스페이스에 생동감 넘치는 활력을 불어넣습니다.
* **성능 최적화의 정점:** 고사양 그래픽 장비 없이도 **저사양 PC 및 노트북에서 끊김 없이 구동**되는 최적화 성능을 자랑합니다. 이는 하드웨어 교체 비용을 발생시키지 않는 또 다른 경제적 이점입니다.
* **Zero-Install(무설치) 접속:** 별도의 프로그램 설치 과정 없이 크롬이나 엣지 등 웹 브라우저 접속만으로 즉시 업무 공간에 진입할 수 있어 사용자 편의성을 극대화했습니다.

## 4\. 고도화된 협업 및 관리 기능 (Core Features)

* **인사 및 근태 관리 시스템**
  * **실시간 근무 현황:** 로그인/로그아웃과 연동된 자동 출퇴근(Clock-in/out) 기록 및 부서별 실시간 상태(업무, 회의, 외근, 자리비움) 동기화.
  * **데이터 자산화:** 전사 근태 타임라인 모니터링 및 급여 정산 연동을 위한 **엑셀(CSV) 다운로드** 기능 제공.
* **지능형 협업 도구**
  * **100% 사내 LiveKit SFU 미디어 단일화 (P2P 완전 제거):** 기존 P2P 방식의 치명적 한계였던 사용자 간 사설 IP 노출과 기업 방화벽/VPN 차단 문제를 원천 차단했습니다. 1:1 통화, 개인 화면 공유, 회의실 화상회의까지 모든 미디어가 사내 온프레미스 LiveKit SFU 서버로만 안전하게 암호화 중계됩니다.
  * **마주치면 들리는 근거리 대화 (Spatial Audio):** 회의실을 별도로 잡지 않아도 3D 오피스에서 동료 아바타에게 다가가면 자연스럽게 목소리가 들리는 거리 기반 실시간 음성 엔진을 지원합니다. 발화 시 아바타 머리 위 스피킹 링 시각화로 즉각적인 의사소통이 가능합니다.
  * **회의실별 독립 격리 화상회의:** 방(Room) 단위로 완벽히 격리된 LiveKit SFU 채널을 제공하여 방 간 소리·화면 간섭이 일체 없습니다. 발표자의 PC 부하 없이 다자간 고화질 회의를 지원합니다.
  * **실시간 화면 공유:** 발표자 화면의 **네온 글로우(Neon Glow)** 효과와 1:1 전체화면 집중 뷰어로 몰입도를 극대화하며, 시스템/탭 오디오까지 끊김 없이 동시 송출합니다.
* **대규모 소통 공간**
  * **100석 대강당 / 타운홀 미팅:** 현재 100석 규모(향후 200석 지원 예정)의 대형 객석과 발표 무대를 갖춘 전사 세미나 및 설명회 강당입니다.
  * **발표자·청중 권한 분리 및 손들기:** 발표자가 세미나를 주도하며, 청중은 '손들기(발언권 요청)'를 통해 발표자의 승인을 얻어 마이크를 켜고 질의응답을 진행합니다.
  * **음향 동시 송출 & 에코 방지:** 발표자의 화면 공유 시 고품질 시스템 사운드가 동시 송출되며, Web Audio 기반 에코 캔슬링 및 중복 음향 방지 기술로 쾌적한 세미나 환경을 제공합니다.
  * **외부 게스트 초대:** 외부 협력사, VIP, 방문객을 위한 전용 초대 링크 발급 기능을 지원합니다.

## 5\. 철저한 보안 및 기술 아키텍처

워크넥서스는 전문 IT 인력이 부족한 중소기업(SME)도 손쉽게 운영할 수 있는 고안보 아키텍처를 지향합니다.

* **100% 사내 완결형 온프레미스:** 모든 데이터와 미디어 스트림이 기업 내부 서버에서 처리되어 외부 유출 통로를 원천 차단합니다.
* **Windows 네이티브 환경:** Docker나 Linux, Redis 등 **복잡한 가상화나 추가 소프트웨어 설치 없이** Windows 환경에서 즉시 구동되는 포터블 엔진을 채택했습니다.
* **기술적 무결성:** **SQLite 기반 고속 DB**와 **Ed25519 암호화 라이선스** 체계를 통해 데이터 무결성과 시스템 보안을 동시에 확보했습니다.
* **보안 외부 접속 주소 지원:** Cloudflare Named Tunnel 기술을 적용하여 고정 IP나 복잡한 VPN 설정 없이도 **안전한 외부 접속 주소(HTTPS/WSS)를 즉시 할당**받아 재택근무 환경을 구축할 수 있습니다.

| 구분          | 사내 접속 (사내망)            | 사외 접속 (재택/외근)               |
| ----------- | ---------------------- | --------------------------- |
| **접속 주소**   | 사내 IP (예: 192.168.x.x) | **고정 보안 도메인 (HTTPS)**       |
| **핵심 기술**   | 내부 방화벽 포트 제어           | **Cloudflare Named Tunnel** |
| **비즈니스 가치** | 내부망 보안 완결성             | 보안 설정 간소화 및 재택 효율성          |

## 6\. 공급 및 도입 프로세스 (B2B 모델)

1. **3D 커스텀 스튜디오 설계:** 공급사는 **금융, 공공기관, 학교, 연구소** 등 8대 업종별 템플릿을 기반으로 고객사의 조직 구조에 최적화된 가상 사옥을 직접 설계합니다.
2. **암호화 라이선스 발급:** 고객사의 공간 정보와 전용 터널 도메인이 포함된 **Ed25519 기반 암호화 라이선스(.lic)** 파일을 생성합니다.
3. **Single Golden Binary 즉시 가동:** 고객사는 단일 실행 파일에 라이선스를 등록하는 것만으로 즉시 우리 회사만의 가상 사옥을 오픈할 수 있습니다.

## 7\. 도입 기대효과 및 결론

워크넥서스 도입은 기업에 다음과 같은 전략적 가치를 제공합니다.

1. **압도적 유지비용 절감:** 매월 발생하는 구독형 솔루션 비용을 전액 절감하여 장기적 운영 비용을 혁신합니다.
2. **완벽한 데이터 주권 확보:** 기업의 모든 소통 기록을 사내 자산화하여 정보 유출 리스크를 원천 제거합니다.
3. **디지털 소속감 및 협업 강화:** 우리 회사만의 고유한 가상 사옥을 통해 하이브리드 근무 환경에서도 임직원의 결속력을 높입니다.

**워크넥서스는 단순한 소통 도구를 넘어, 기업의 디지털 자산이 되는 진정한 '독립 가상 사옥'입니다.**

## 8\. 기술 사양 및 지원 (Appendix)

### [시스템 권장 사양]

| 항목          | 사양 및 특징                                             |
| ----------- | --------------------------------------------------- |
| **서버 운영체제** | Windows 10 / 11 또는 Windows Server (Windows 네이티브 구동) |
| **서버 하드웨어** | CPU 4코어 이상, RAM 8GB 이상, **유선 LAN 연결 권장**            |
| **지원 브라우저** | Chrome, Edge, Whale, Safari (최신 버전 권장)              |
| **설치 편의성**  | **포터블 런타임 포함으로 별도 Node.js 또는 Docker 설치 불필요**        |

### [주요 네트워크 포트 정보]

| 포트 번호            | 프로토콜        | 용도                                        |
| ---------------- | ----------- | ----------------------------------------- |
| **3001**         | HTTP / WS   | 통합 온프레미스 운영 서버 (3D 웹앱, DB, API 통합)        |
| **7880 / 7881**  | HTTP / TCP  | LiveKit 미디어 신호 서버 및 미디어 대체 경로             |
| **50000\~50200** | UDP         | 실시간 화상 및 음성 데이터 전송 (기본 경로)                |
| **443**          | HTTPS / WSS | **보안 외부 접속 전용 (Cloudflare Named Tunnel)** |
