## 1. 1.0.7에 포함된 변경

### 1.1 모바일·태블릿 조작 (`db4a59c`, `45df8bf`)
- 휴대폰 화면(700px 이하)의 하단 버튼에 짧은 이름을 붙였다(마이크·주변소리·카메라·화면공유·채팅·설정). 숨어 있던 기능은 **더보기** 메뉴에 모았다(아바타 꾸미기·내 자리 저장·동료·프로필/설정·조작 안내·근무 상태).
- 터치 기기에는 왼쪽 아래 **이동 조이스틱**(끝까지 밀면 달리기)과 오른쪽 **앉기/일어서기** 버튼이 보인다(`MobileMovePad`).
- 태블릿: 예전에는 짧은 변 1024px 이하만 모바일로 판정해서, 큰 태블릿이나 iPad 데스크톱 모드에는 조이스틱이 나오지 않았다. 이제 화면 크기와 관계없이 터치가 되는 기기면 보인다. **설정 > 화면** 또는 **더보기**에서 자동/항상 표시/숨김을 고르고, 기기별로 기억한다(`src/hooks/useMovePad.ts`).
- 회의 예약·공지 센터를 모바일 화면에 맞게 배치했다(카드 버튼이 세로로 쪼개지던 문제).

### 1.2 방 격리: 이동한 뒤 송출·참여 (`db4a59c`)
- 다른 층·다른 방에 있으면서 회의실 스크린으로 송출하거나 진행 중인 회의 창을 열 수 있던 문제를 고쳤다. 화면 공유 선택 창의 버튼이 **이동해서 송출 / 이동해서 회의 참여**로 바뀌고, 누르면 캐릭터를 그 방으로 옮긴 뒤 진행한다.

### 1.3 아바타 반응 메뉴 (`45df8bf`, 서버 변경 포함)
- 하단 손들기 버튼이 **😀 반응** 버튼으로 바뀌었다. 메뉴: ✋ 손들기(유지) · 👋 안녕하세요 · 👍 좋아요 · 👎 반대 · 👏 박수 · ❤️ 하트 · 😂 웃음 · ❓ 질문.
- 반응은 약 3초 동안 머리 위에 표시된다. 안녕하세요는 손 흔들기 동작, 박수는 손뼉 동작과 반짝이, 하트는 떠오르는 하트가 함께 나온다.
- 서버(`server/index.js`)가 `reaction` 메시지를 허용 목록·0.8초 간격 제한으로 검사해 같은 건물 접속자에게 `peer_reaction`으로 전달한다. 저장하지 않는다.
- **서버와 앱이 함께 1.0.7이어야 한다.** 1.0.6 서버는 반응을 전달하지 않아 내 화면에만 보인다.

### 1.4 디지털 사내 아카이브 게시판 (`ef431fd`)
- **E 키**: 스튜디오에서 배치한 게시판(`gallery_archive_board`)에는 다가갔을 때의 E 키 안내가 없었다. 보드 앞에 가면 "N층 디지털 사내 아카이브 · 게시판 열기 (E)"가 뜬다.
- **클릭**: 보드 위 글자(3D 위에 겹친 HTML)와 HUD 오른쪽 위 묶음의 빈 공간이 클릭을 가로챘다. 둘 다 클릭을 통과시키도록 고쳤다.

### 1.5 벽걸이 소품 자동 방향 (`ef431fd`)
- 화이트보드·아카이브 게시판·공유 스크린이 벽에서 4m 안에 있으면 앞면이 방 안쪽을 보게 한다. 뒷벽 0°, 출입문 벽 180°, 왼쪽 벽 90°, 오른쪽 벽 270°다.
- 스튜디오는 벽 근처에 내려놓을 때 각도를 바꿔 저장한다. 평면도의 앞면 쪽 가장자리에 금색 선이 표시된다.
- 3D 오피스는 이미 저장된 건물도 같은 규칙으로 보정해 그린다. 예를 들어 2F 임원실 화이트보드가 벽을 보던 것이 방 쪽을 보게 됐다.
- 상세 규칙: `0. 방_건물_커스텀스튜디오_프리셋_연동_및_계약연계_가이드.md` 9.8절.

### 1.6 보안 검토 후속 (`04de25c`, `c3e8123`, `ba83e93`, 서버 변경 포함)
- 고객 매뉴얼 통일: 버전 1.0.7, 미디어 포트(Windows 50000~50200 / Linux 50000~50300), 데이터 경로 표현("외부 전송 없음" → 미디어·DB는 사내, 고정 도메인 사용 시 웹 경로는 Cloudflare 경유, 폐쇄망 모드는 외부 연결 없음).
- 관리자 보안 정책(관리자 센터 → 사원 및 인사 관리, 모두 기본 꺼짐)
  - **로그인 전 사원 목록 숨기기**: 켜면 이메일 로그인만 허용.
  - **초기 비밀번호 무작위 발급**: 기본은 기존 1234. 켜면 10자리 무작위 값을 관리자에게 한 번만 표시. 사원 수정 화면에 **비밀번호 초기화** 추가.
  - **미사용 자동 로그아웃**: 30분~8시간. 입력이 없고 회의·통화·화면공유 중도 아니면 로그아웃, 1분 전 경고, 근태는 **자리 비움**으로 기록.
- 초기 비밀번호를 바꾸기 전에는 서버가 API·오피스 입장을 거부.
- 글꼴을 앱에 내장(Google Fonts 요청 없음). 관리자 콘솔의 "100%" 문구 정리.
- 기존 결함 수정: 근태 저장에 같은 id를 보내면 서버 전체가 멈추던 문제 → 409.

### 1.7 버전 표기 (`089fb73`)
- `release-manifest.json` 기준으로 버전 표기를 모두 1.0.7로 맞추고 `npm run verify:release-version`을 통과했다. 매뉴얼 PDF 11개도 다시 만들었다.
- 1.0.6 때 **v1.0.5로 남아 있던 화면 표시 7곳**을 함께 고쳤다(HUD 건물 이름 옆, 관리자 콘솔 2곳, 엔터프라이즈 포털, 사내 홈, 트레이 메뉴 머리, 서버 안내 페이지).

## 4. Linux 묶음 빌드 메모

### 4.1 우분투 시험 서버 고장 → WSL2로 전환 (2026-10-12)
- 우분투 시험 서버(i3-4150)는 로그를 남기지 않고 자주 멈췄다. 부팅 2~3분 뒤 멈춘 기록이 여러 번 있었고, 빌드 도중에도 멈췄다. 결국 고장 나 수리 중이다. 디스크 오류나 메모리 부족(OOM) 기록은 없어 전원·메모리·발열 같은 하드웨어 문제로 본다.
- 대신 이 PC(Windows 11 Pro, Ryzen 5 7530U)에 WSL2를 설치해 Linux 묶음을 만든다. Docker Desktop은 쓰지 않고 WSL 안에 Docker Engine을 설치했다(무료).
- 설치 순서(한 번만):
  1. 관리자 권한으로 `wsl --install -d Ubuntu-24.04 --no-launch` → 가상 머신 플랫폼이 켜지면 재부팅.
  2. Microsoft Store 경로의 다운로드가 0바이트에서 멈춰, 우분투 공식 WSL 이미지를 국내 미러에서 직접 받았다: `https://mirror.kakao.com/ubuntu-releases/24.04.5/ubuntu-24.04.5-wsl-amd64.wsl`. SHA-256이 공식 값(`bb415d82…6039e`, Microsoft `DistributionInfo.json`)과 같은지 확인했다.
  3. `wsl --import worknexus-build C:\WSL\worknexus-build C:\WSL\downloads\ubuntu-24.04.5-wsl-amd64.wsl --version 2` — 빌드 전용 배포판, root로 실행, systemd 사용.
  4. WSL 안에서 apt 서버를 `mirror.kakao.com`으로 바꾸고, Docker 공식 저장소에서 `docker-ce`·`docker-buildx-plugin`·`docker-compose-plugin` 설치(Docker 29.9.0, Compose v5.6.0).
- 빌드할 때마다:
  ```bash
  # Windows(프로젝트 루트) — 커밋된 소스를 LF로 묶기
  git -c core.autocrlf=false archive --format=tar.gz -o /c/WSL/worknexus-src-<버전>.tar.gz HEAD -- . ':!mdfile' ':!marketing-public'
  # WSL 안(root) — WSL 리눅스 디스크에 풀어서 빌드(/mnt/c 위에서 빌드하면 느리다)
  mkdir -p /root/worknexus/build && tar -xzf /mnt/c/WSL/worknexus-src-<버전>.tar.gz -C /root/worknexus/build
  cd /root/worknexus/build && bash scripts/package-linux.sh
  cp dist-packages/worknexus-server-linux-<버전>.tar.gz /mnt/c/calamusAppBuild/Virtual_Office/dist-packages/
  ```
- 빌드 스크립트는 `C:\WSL\build-linux.sh`에 남겨 두었다(`wsl -d worknexus-build -u root -- bash /mnt/c/WSL/build-linux.sh`).

### 4.2 이전 원격 빌드(우분투 시험 서버) 메모
- 절차는 14번 문서 4장과 같다. 소스는 `git -c core.autocrlf=false archive ... HEAD -- . ':!mdfile' ':!marketing-public'`로 묶는다(1.4MB). 문서 폴더를 빼지 않으면 290MB가 된다.
- 처음 시도할 때는 서버가 응답하지 않았다(22·9090 포트 모두 시간 초과). 서버 전원·네트워크를 확인한 뒤 다시 시도해 성공했다. 접속이 안 되면 서버가 켜져 있는지부터 확인한다.
- 서버에 올린 소스 압축 파일과 시작 스크립트는 지웠다. `~/worknexus/build-1.0.7` 폴더와 `~/worknexus/build-1.0.7.log`는 남겼다.

## 5. 공급자 포털에 올리기 (담당자 작업)
1. `https://worknexus.calamus.ai.kr/manage` → 릴리스
2. 버전 `1.0.7`
