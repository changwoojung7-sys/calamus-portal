# 타운홀 세미나 운영 매뉴얼

작성일: 2026-09-26 · 대상: 세미나를 예약·진행하는 직원(예약자·발표자), 참석자, 사내 관리자

타운홀은 3D 오피스와 별도로 운영되는 **강당형 세미나 공간**입니다. 전사 발표, 제품 설명회, 외부 고객 초청 세미나처럼 여러 사람이 한 화면을 함께 보고 질문하는 행사에 사용합니다. 영상·음성·화면공유는 모두 사내 서버의 **LiveKit SFU**로만 전달됩니다(사용자 간 P2P 연결 없음).

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 강당 좌석 | 210석(한 줄 14석 × 15줄, 좌·중·우 3개 블록과 통로 2개) |
| 실제 입장 인원 | 계약(라이선스) 한도. 현재 기본 **100명**. 앞줄부터 자리가 배정됩니다 |
| 발표자 | **예약자 포함 최대 5명**(예약자 1명 + 발표자 4명) |
| 예약 | **직원이면 누구나** 가능(외부 게스트 제외) |
| 수정·초대링크 | 예약자와 그 행사의 발표자 |
| 삭제 | 예약자(관리자는 비상용으로 모두 가능) |
| 행사 시작·종료·다시 열기 | 예약자와 발표자 누구나 |
| 녹화 | 발표자가 **자기 PC에서 자기 공유 화면**을 녹화(서버 부하 없음) |

> [!NOTE]
> 입장 인원 한도는 라이선스 계약값입니다. 200명 이상이 필요하면 공급자에게 라이선스 발급 옵션으로 요청하세요. 고객사 서버 회선을 함께 검토합니다(200명이 화면공유 한 개를 볼 때 서버 송출량은 최대 약 300~500Mbps).

## 2. 역할과 권한

| 할 수 있는 일 | 예약자 | 발표자 | 참석자(직원) | 외부 게스트 | 관리자 |
|---|:-:|:-:|:-:|:-:|:-:|
| 새 세미나 예약 | ✅ | ✅ | ✅ | – | ✅ |
| 일정·명단 수정, 초대링크 확인·재발급 | ✅ | ✅ | – | – | ✅(비상용) |
| 예약 삭제 | ✅ | – | – | – | ✅(비상용) |
| 행사 시작하고 입장 | ✅ | ✅ | – | – | ✅ |
| 무대 이동·착석(WASD·F), 화면공유(E) | ✅ | ✅ | – | – | – |
| 마이크·카메라 | ✅ | ✅ | 발언 승인 시 | 발언 승인 시 | – |
| 전체 음소거, 질문 발언 승인·회수, 녹화 | ✅ | ✅ | – | – | – |
| 손들기·질문 등록, 채팅 | – | – | ✅ | ✅ | – |
| 행사 종료, 행사 다시 열기 | ✅ | ✅ | – | – | ✅ |

- "예약자"는 세미나를 등록한 사람입니다. 발표자가 일정을 수정해도 예약자는 바뀌지 않습니다.
- 명단에 없는 직원도 행사가 진행 중이면 참석자로 입장할 수 있습니다(인원 한도 안에서).

## 3. 세미나 예약하기 (행사 전)

1. 사내 포털에서 **`[🏛️ 타운홀 로비 입장]`** → 오른쪽 패널의 **`[세미나 예약·참석자·일정 관리]`**를 누릅니다.
2. **새 세미나 예약** 양식을 채웁니다.
   - 세미나 제목, 행사 설명
   - 시작 일시·종료 일시(종료가 시작보다 뒤여야 합니다)
   - **발표자 지정**: 최대 4명까지 체크합니다(예약자 본인 포함 5명). 5번째를 고르면 안내 문구가 나오고 선택되지 않습니다.
   - **직원 참석자 사전 등록**: 최대 100명. 사전 등록은 선택 사항입니다.
   - **외부 게스트 초대 링크 등록 허용**: 외부 고객을 부를 때 켭니다.
3. **`[세미나 예약 등록]`**을 누르면 예약 목록에 올라가고, 게스트 허용 시 **외부 초대 링크**가 창 위쪽에 표시됩니다. **복사** 버튼으로 복사해 초대 메일에 붙입니다.

### 3.1 수정·삭제·초대링크

예약 목록의 아이콘으로 관리합니다. 예약자와 발표자에게만 보입니다.

| 아이콘 | 기능 | 누가 |
|---|---|---|
| 🔗 | 초대 링크 다시 보기 | 예약자·발표자 |
| ✏️ | 일정·명단 수정 → 아래 양식에서 고친 뒤 **`[일정·참석자 수정 저장]`** | 예약자·발표자 |
| 🗑 | 예약 삭제(참석자 명단도 함께 삭제) | 예약자 |

- 수정·삭제는 **예정** 상태에서만 가능합니다. 진행 중이거나 종료된 행사는 수정할 수 없습니다.
- 초대 링크가 외부로 유출됐다면 🔗 → **`[🔄 재발급 (기존 링크 무효화)]`**을 누릅니다. 기존 링크는 즉시 쓸 수 없게 됩니다.

---

## 4. 행사 당일 — 시작과 입장

### 4.1 예약자·발표자

1. 타운홀 로비에서 세미나를 선택합니다.
2. **입장 전 본인확인** 체크 → **`[행사 시작하고 입장]`**을 누릅니다.
   - 예약자가 없어도 **발표자 누구나** 시작할 수 있습니다.
   - 이미 다른 발표자가 시작했다면 **`[본인확인 후 세미나 입장]`**으로 들어갑니다.
3. 무대 위에 자신의 캐릭터가 나타나면 준비 완료입니다.

### 4.2 참석자(직원)

1. 로비에서 세미나를 선택하고 **입장 전 본인확인**에 체크합니다.
2. 행사가 시작되면 **`[본인확인 후 세미나 입장]`** 버튼이 나타납니다. 로비는 **5초마다 자동으로 상태를 확인**하므로 새로고침할 필요가 없습니다.
3. 입장하면 앞줄부터 좌석이 배정되고, 객석에 캐릭터와 이름표가 표시됩니다.

### 4.3 외부 게스트

1. 받은 초대 링크를 엽니다.
2. 이름·회사/소속·이메일을 입력하고 **행사 참석 정보 수집 동의**에 체크한 뒤 **`[등록하고 입장]`**을 누릅니다.
3. 행사가 시작되기 전이면 입장할 수 없습니다. 시작 시각 이후 다시 시도하도록 안내하세요.

## 5. 발표자 조작

### 5.1 무대 이동과 화면

| 조작 | 방법 |
|---|---|
| 무대 위 이동 | WASD 또는 방향키, 무대 바닥 클릭 |
| 착석·기립 | F |
| 화면공유 시작·종료 | E 또는 하단 **`[화면공유 (E)]`** |
| 시점 바꾸기 | **`[객석 보기]`**(강당 전체) / **`[무대 보기]`**(무대 옆) |
| 공유 화면 크게 보기 | **`[화면 크게 보기]`** |

- 화면공유는 **한 번에 한 발표자**만 할 수 있습니다. 다른 발표자가 공유 중이면 끝난 뒤 공유하세요.
- 영상의 소리까지 보내려면 공유 선택 창에서 **탭 공유 + "탭 오디오 공유"**(Windows는 "시스템 오디오 공유")를 켜야 합니다.

### 5.2 마이크·카메라

하단 버튼의 색으로 상태를 알 수 있습니다.

| 버튼 | 뜻 |
|---|---|
| 🟢 **마이크 켜짐** / 🔴 **음소거 됨** | 누를 때마다 켜고 끕니다 |
| 🟢 **카메라 켜짐** / 🔴 **카메라 Off** | 켜면 오른쪽 **참석자 화면** 타일에 내 얼굴이 나옵니다 |

- 참석자 화면 타일 오른쪽 아래의 🎤/🔇로 각 발표자의 마이크 상태를, 초록 테두리로 지금 말하는 사람을 볼 수 있습니다.

### 5.3 공유 소리 내 스피커 (소리 겹침 방지)

발표자 하단의 **`[공유 소리 내 스피커: 끔/켬]`** 버튼입니다. **기본값은 "끔"**입니다.

- **끔(기본, 권장)**: 공유한 영상의 소리를 **내 PC 스피커로 내보내지 않습니다**. 참석자에게는 정상적으로 전달됩니다. 내 마이크가 그 소리를 다시 잡지 않아 참석자에게 **소리가 겹쳐(하울링처럼) 들리지 않습니다.** 대신 발표자 본인은 영상 소리를 듣지 못합니다.
- **켬**: 발표자도 영상 소리를 듣습니다. 이때 마이크가 켜져 있으면 스피커 소리가 마이크로 다시 들어가 참석자에게 겹쳐 들릴 수 있습니다. 반드시 **이어폰**을 사용하세요. 이 상태에서 마이크를 켜면 화면에 ⚠️ 경고가 표시됩니다.
- 설정은 **화면공유를 시작할 때** 적용됩니다. 공유 중에 바꿨다면 공유를 종료했다가 다시 시작하세요.
- 설정은 이 브라우저에 기억됩니다.

### 5.4 녹화

- 화면공유를 시작하면 **`[녹화]`** 버튼이 켜집니다. 누르면 **내 PC에서 내 공유 화면**을 녹화하고, **`[녹화 종료]`**를 누르면 저장 안내 창이 뜹니다.
- 서버를 거치지 않으므로 발표자 여러 명이 각자 녹화해도 서버·네트워크 부하는 없습니다. 녹화하는 PC의 CPU만 사용합니다(저사양 노트북은 공유와 녹화를 동시에 하면 버벅일 수 있습니다).
- 녹화 중에 **미팅 나가기**나 **사무공간**을 누르면 먼저 녹화를 끝내고 파일을 받도록 안내합니다.

### 5.5 질문 받기

1. 참석자가 손을 들면 오른쪽 패널 **질문·발언 대기** 목록에 순서대로 나타나고, 객석 캐릭터 머리 위에 ✋가 뜹니다.
2. **`[발언 승인]`**을 누르면 그 참석자에게 마이크·카메라 버튼이 생깁니다. 한 번에 한 명만 승인할 수 있습니다.
3. 질문이 끝나면 **`[발언 종료 / 승인 회수]`**를 누릅니다. 참석자의 마이크·카메라가 자동으로 꺼집니다.
4. 소음이 들리면 **`[전체 음소거]`**로 모든 마이크를 한 번에 끕니다.

## 6. 참석자 이용

- **질문하기**: 질문 내용을 적고(선택) **`[✋ 손들기 / 질문 등록]`**을 누릅니다. 승인되면 마이크·카메라 버튼이 나타납니다. 직접 켜야 합니다.
- **채팅**: 오른쪽 패널의 **`[💬 채팅]`** 탭. **`[🗗]`**로 채팅만 별도 창으로 띄울 수 있습니다(듀얼 모니터).
- **화면 크게 보기**: 공유 화면을 전체 화면으로 봅니다.
- **소리가 안 들리면**: 화면을 한 번 클릭하세요. 브라우저가 자동 재생을 막은 경우 클릭하면 재생됩니다.

### 6.1 나가기 버튼 두 가지

| 버튼 | 위치 | 동작 |
|---|---|---|
| **`[← 사무공간]`** | 좌측 상단 | 세미나에서 나가며 **3D 사무실로 돌아갑니다**(직원 전용, 게스트에게는 보이지 않음) |
| **`[미팅 나가기]`** (빨간 버튼) | 오른쪽 패널 맨 아래 | 세미나에서만 나가고 **로비에 남습니다**. 다시 입장할 수 있습니다. 게스트는 "참석해 주셔서 감사합니다" 화면으로 갑니다 |

## 7. 행사 종료와 복구

1. 예약자 또는 발표자가 오른쪽 패널 맨 아래 **`[행사 종료]`**를 누릅니다.
2. "행사를 종료할까요?" 확인 창에서 확인하면 **모든 참석자의 연결이 끊깁니다.**
3. **잘못 눌렀다면**: 로비에 남은 예약자·발표자에게 **`[↺ 행사 다시 열기 (종료 취소)]`** 버튼이 보입니다. 누르면 **같은 행사**(명단·초대링크 그대로)가 다시 진행 중이 되고 바로 입장합니다.
4. 다시 연 뒤에는 참석자에게 **다시 입장**해 달라고 안내하세요(채팅은 연결이 끊겨 보이지 않으므로 메신저 등으로 알립니다). 게스트는 같은 초대 링크로 다시 등록해 입장합니다.

## 8. 모바일·태블릿

| 화면 | 배치 | 권장 용도 |
|---|---|---|
| 세로 | 무대 → 버튼 → 패널이 위에서 아래로 쌓이고 스크롤됩니다 | 채팅·질문 |
| 가로 | 무대가 화면 높이에 맞춰지고, 하단 버튼은 **한 줄**로 좌우로 넘겨 봅니다 | 발표 화면 시청 |

- 공유 화면을 잘 보려면 가로로 돌리고 **`[화면 크게 보기]`**를 사용하세요.
- iPhone·iPad에서 소리가 안 들리면 화면을 한 번 누르세요.

## 9. 문제 해결

| 증상 | 원인·조치 |
|---|---|
| 공유 영상 소리가 두 번 겹치거나 울림 | 발표자 스피커 소리가 발표자 마이크로 다시 들어간 경우입니다. 발표자가 **공유 소리 내 스피커: 끔**(기본) 상태로 **공유를 다시 시작**하거나 이어폰을 사용합니다 |
| 공유 영상 소리가 참석자에게 안 들림 | 공유 선택 창에서 "탭 오디오 공유"(또는 시스템 오디오)를 켜지 않았습니다. 공유를 다시 시작하며 켭니다. 참석자는 화면을 한 번 클릭합니다 |
| "행사 시작하고 입장" 버튼이 없음 | 예약 명단의 예약자·발표자가 아닙니다. 예약자에게 발표자로 추가를 요청합니다 |
| 참석자에게 입장 버튼이 안 보임 | 아직 행사가 시작되지 않았습니다. 시작되면 5초 안에 자동으로 나타납니다 |
| 발표자 수정 버튼(✏️)이 안 보임 | 진행 중·종료된 행사는 수정할 수 없습니다. 예정 상태에서만 수정합니다 |
| 녹화 버튼이 눌리지 않음 | 화면공유를 먼저 시작해야 합니다 |
| 발표자 5명을 고를 수 없음 | 예약자 포함 5명이 한도입니다. 예약자 외 4명까지 선택합니다 |
| 인원이 다 찼다고 나옴 | 계약 입장 한도(기본 100명)에 도달했습니다. 한도 확대는 라이선스 발급 옵션으로 공급자에게 요청합니다 |
| 게스트가 링크로 입장 못 함 | 행사가 시작 전이거나, 링크가 재발급으로 무효화됐거나, 게스트 등록이 꺼져 있습니다 |

---

## 10. 관리자 설정

- **타운홀 사용 여부·게스트 링크 기본값**: 건물 템플릿 스튜디오의 **"타운홀 설정"**에서 켜고 끕니다. 꺼 두면 포털의 타운홀 진입 버튼이 보이지 않습니다.
- **강당 브랜딩**: 무대 벽의 회사명·로고는 관리자 콘솔 **"라이선스"** 탭에서 설정합니다(비워 두면 계약사명 표시).
- **50명 샘플 리허설**: 관리자 전용 버튼 **`[50명 + 현재 직원 발표자 샘플 시작]`**으로 가상 참석자를 채워 강당 화면을 미리 볼 수 있습니다(데모 설치본).
- **감사 기록**: 예약·수정·삭제·시작·종료·다시 열기·초대코드 재발급은 서버 감사 로그에 남습니다.

## 11. 운영 체크리스트

**행사 하루 전**
- [ ] 예약 일정, 발표자(최대 4명 + 예약자), 참석자 명단 확인
- [ ] 외부 게스트가 있으면 초대 링크 발송
- [ ] 발표자 전원이 테스트 입장해 화면공유(+탭 오디오)·마이크·카메라 확인

**행사 30분 전**
- [ ] 예약자 또는 발표자가 **행사 시작하고 입장**
- [ ] 발표자는 이어폰 착용 또는 **공유 소리 내 스피커: 끔** 확인
- [ ] 녹화할 발표자는 저장 공간 확인

**행사 중**
- [ ] 질문·발언 대기 목록 확인, 한 번에 한 명씩 발언 승인
- [ ] 소음이 생기면 전체 음소거

**행사 후**
- [ ] 녹화 파일 저장 확인
- [ ] **행사 종료**. 잘못 종료했다면 즉시 **행사 다시 열기**
