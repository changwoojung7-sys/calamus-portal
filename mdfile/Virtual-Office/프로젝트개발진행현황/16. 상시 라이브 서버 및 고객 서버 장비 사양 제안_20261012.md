## 1. 우리가 쓸 상시 라이브 서버 (칼라무스 보유)

### 1.1 용도

한 대로 아래 네 가지를 함께 한다. 고장 난 우분투 시험 서버(i3-4150)를 대체한다.

1. **도그푸딩**: 칼라무스·관계사가 매일 출근·회의·화면공유를 이 서버에서 한다.
2. **정기 라이브 시연**: 매주 30분 타운홀 시연(외부 참가자 게스트 입장).
3. **라이브 체험 사옥**: 공개 체험 사이트에서 실제 음성·영상까지 체험하게 하는 상시 서버.
4. **릴리스 검증**: 새 버전을 고객에게 내기 전 Linux 패키지 설치·업데이트 시험.

### 1.2 필요한 성능 산정

| 쓰임 | 예상 부하 | 근거 |
|---|---|---|
| 도그푸딩 | 동시 10~30명, 방 회의 1~3개 | 30명 회의 10회 반복 시험 통과 |
| 라이브 시연 | 타운홀 50~100명, 발표 화면 1080p 1개 | 강당 100명 1080p: 송신 약 300Mbps, 미디어 CPU 약 3.6코어 |
| 여유 | 시연 중 도그푸딩 동시 진행, 업데이트 시험 | — |

→ 기존 권장표의 **"강당·타운홀" 등급**(12~16코어, 32GB, 2.5Gbps 권장)에 가깝게, 다만 시연 규모(100명 이하)를 고려해 **8코어 16스레드 이상 · 32GB · 2.5GbE**면 충분하다.

### 1.3 권장 사양

| 항목 | 권장 | 이유 |
|---|---|---|
| CPU | x86-64, **8코어 16스레드 이상** (예: AMD Ryzen 7 7840HS/8845HS급, Intel Core Ultra 7급) | 미디어 중계(LiveKit) + 웹서버 + Docker 동시 실행. Linux 패키지가 x86-64 기준이라 ARM(맥)은 제외 |
| 메모리 | **32GB** | 고장 난 서버는 7GB에서 여러 서비스를 함께 돌렸다. 시연·도그푸딩·업데이트 시험을 동시에 해도 여유 |
| 저장장치 | **NVMe SSD 1TB** (HDD 사용 금지) | 고장 서버의 시스템 디스크가 오래된 HDD였다. 백업·Docker 이미지 공간 |
| 네트워크 | **2.5GbE 유선**(최소 1GbE), Wi-Fi 사용 안 함 | 타운홀 1080p 송출은 수백 Mbps가 필요하다 |
| 전원 | **UPS 600~850VA** + BIOS "전원 복구 시 자동 켜짐" | 정전·순간 단전 후 자동 복구 |
| 냉각 | 미니 PC는 통풍이 되는 곳, 먼지 정기 청소 | 고장 서버는 로그 없이 멈췄다(전원·발열 의심) |
| OS | Ubuntu Server 24.04 LTS(데스크톱 없이) | 기존 Linux 패키지 그대로 사용. 불필요한 서비스(데스크톱, microk8s, Nextcloud 등)는 설치하지 않는다 |

### 1.4 구입 후보 (대략 가격)

| 안 | 구성 | 대략 가격 | 장점 | 단점 |
|---|---|---|---|---|
| **A. 고성능 미니 PC (권장)** | Ryzen 7 8코어 미니 PC + 32GB + 1TB NVMe + 2.5GbE | 90~130만 원 | 성능 대비 저렴, 작고 조용함 | 제조사 AS가 짧고 택배 AS 위주 |
| B. 비즈니스용 소형 PC | 대기업 제조사 비즈니스 미니 PC(3년 방문 AS 모델) + 32GB + 1TB | 150~220만 원 | 방문 AS, 고객 납품 모델과 같게 맞출 수 있음 | 비싸다 |
| C. 데스크톱 조립 | 8코어 데스크톱 CPU + 32GB + 1TB + 2.5GbE 메인보드 | 100~140만 원 | 냉각 여유·부품 교체 쉬움 | 크고 소음 |
| 공통 | UPS 600~850VA | 10~20만 원 | — | — |

**권장: A안 + UPS (합계 약 100~150만 원)**. 고객 납품용과 같은 모델로 경험을 쌓고 싶으면 B안.

### 1.5 설치·운영 원칙 (고장 서버에서 얻은 교훈)

1. WorkNexus 전용으로 쓴다. 다른 실험 서비스(Kubernetes, Nextcloud 등)를 같이 올리지 않는다.
2. 디스크 상태 점검 도구(`smartmontools`)와 온도 확인 도구(`lm-sensors`)를 설치하고 주 1회 확인한다.
3. 절전·대기 모드를 끈다. BIOS에서 정전 후 자동 켜짐을 설정한다.
4. 백업은 서버 밖(NAS 또는 외장 디스크)에도 둔다.
5. 공인 IP·UDP 경로(11번 문서 6장)를 먼저 확인한다. 외부 참가자의 영상·음성이 안 되면 TURN용 소형 VPS(월 1~2만 원)를 추가한다.
6. Linux 패키지 빌드는 계속 개발 PC의 WSL2에서 하고, 이 서버는 실행·검증만 한다.

## 2. 고객 서버 권장 사양 (가격 단계별)

가격 단계(동시접속 50 / 100 / 200 / 300명)에 맞춘 고객 서버 권장 사양이다. 기존 권장표(사내망 HTTPS 가이드 1-3)와 자체 시험 결과를 기준으로 했다.

| 단계 | 주 사용 형태 | CPU | 메모리 | SSD | 네트워크 | 납품 장비 예 |
|---|---|---|---|---|---|---|
| **Business 50** | 동시 50명, 30명 이하 방 회의 2~3개 | 4~6코어 (8~12스레드) | 16GB | 512GB | 1Gbps 유선 | 비즈니스 미니 PC |
| **Business 100** | 동시 100명, 30명 이하 방 회의 여러 개 | 8코어 16스레드 | 16~32GB | 512GB | 1Gbps 유선 | 비즈니스 미니 PC 상위 |
| **Enterprise 200** | 위 + 강당 100명 발표 또는 타운홀 200명 | 12~16코어 | 32GB | 1TB | **2.5Gbps 권장**(최소 1Gbps 전용) | 소형 타워 서버 |
| **Enterprise 300** | 동시 300명, 타운홀·강당 동시 운영 | 16코어 이상 | 64GB | 1TB 이상 | **2.5Gbps 이상** | 타워 서버(이중 전원 권장) |

- 공급자 포털 계약 화면에 보이는 권장 사양은 **최소** 사양(50·100명은 4코어·8GB 등급)이고, 위 표는 여유를 둔 **납품 권장** 사양이다.
- 모든 단계: 서버는 **유선 연결**, SSD 사용, UPS 권장. Windows 설치판·Linux 도커판 모두 가능.
- 타운홀 200명·강당 100명 1080p 송출은 서버 업로드 대역폭이 가장 큰 제약이다(강당 100명 약 300Mbps 측정). 사외 참가자가 많으면 회선 업로드 속도를 먼저 확인한다.
- Business 50은 동시접속이 50명이라 **타운홀도 50명까지만** 들어올 수 있다(외부 게스트 포함). 큰 행사가 필요하면 가격표의 "행사 패스"(17번 문서)로 한 달간 상향한다. 이때 서버 사양이 부족하면 임시 서버를 함께 대여한다.
- 위 사양은 자체 통제 환경의 시험값에 여유를 둔 권장값이며, 고객 환경(카메라 수·화면 품질·외부망 비율)에 따라 설치 후 검수(11번 매뉴얼)로 확인한다.

### 2.1 서버 포함 구매형 납품 장비 원가 (대략)

| 단계 | 장비 원가(대략) | 비고 |
|---|---|---|
| Business 50 | 100~150만 원 | 비즈니스 미니 PC + UPS |
| Business 100 | 150~220만 원 | 상위 미니 PC + UPS |
| Enterprise 200 | 250~400만 원 | 소형 타워 서버 + UPS |
| Enterprise 300 | 400~600만 원 | 타워 서버 + UPS |

가격표(17번 문서)의 서버 포함 구매형 가격은 이 원가를 기준으로 했다.
