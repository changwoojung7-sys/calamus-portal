## 4. 공급자 포털 업로드 (사람이 진행)

공급자 포털의 릴리스 API는 **Cloudflare Access 로그인 토큰**(`Cf-Access-Jwt-Assertion`)이 있어야 하며, 이 토큰은 담당자 브라우저의 로그인에만 있다. 그래서 에이전트(터미널)는 업로드할 수 없고 담당자가 올린다.

1. `https://worknexus.calamus.ai.kr/manage` → **릴리스** → 버전 **1.0.8**.
2. 운영체제별로 올린다: Windows 운영(설치 EXE·ZIP), Windows 데모(설치 EXE·ZIP), **Linux 도커 묶음**(`worknexus-server-linux-1.0.8.tar.gz`).
3. 화면의 SHA-256이 위 표와 같은지 확인한 뒤 **서명 후 게시**.
4. 고객 다운로드 포털에서 1.0.8이 보이고 내려받아지는지 확인한다.

### 다음부터 에이전트가 올리게 하려면(선택)

Cloudflare Zero Trust에서 **서비스 토큰**(Client ID·Secret)을 만들고, 공급자 관리 Access 앱 정책에 **Service Auth**로 그 토큰을 허용하면 된다. 서버는 Access 토큰의 AUD로만 판단하므로 코드 변경 없이 동작한다. 토큰은 `.env`에만 두고 커밋하지 않는다.
