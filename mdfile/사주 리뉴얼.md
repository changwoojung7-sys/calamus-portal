# 2. 명리학 데이터 ➔ 현대적 언어 매핑 기준

전통 용어를 직접 노출하지 않고 현대인의 직무/일상 언어로 100% 치환하여 해석합니다.

| 전통 명리학 개념 | 현대적 치환 개념 | 해석 관점 |
| --- | --- | --- |
| **일간(日干)** | **코어 페르소나 (Core Persona)** | 타고난 본캐, 세상을 바라보는 기본 렌즈 |
| **오행(목·화·토·금·수)** | **5대 라이프 에너지 (Energy Balance)** | 성장/추진(목), 열정/표현(화), 안정/중재(토), 원칙/결단(금), 지혜/유연성(수) |
| **비견 / 겁재** | **자기주도성 & 경쟁력** | 독립심, 스타트업 창업가 기질, 동료 및 파트너십 |
| **식신 / 상관** | **생산성 & 크리에이티브** | 콘텐츠 제작 능력, 표현력, 개발/기획 실행력 |
| **편재 / 정재** | **현금흐름 & 자산 관리** | 비즈니스 감각, 파이프라인 구축, 안정적 투자 성향 |
| **편관 / 정관** | **조직 적응력 & 리더십** | 조직 내 포지셔닝, 책임감, 브랜드 구축 및 평판 |
| **편인 / 정인** | **학습력 & 인사이트** | 데이터 흡수력, 기획/분석 전문성, 멘토십 |
| **대운 / 세운** | **매크로 트렌드 & 시즌 주기** | 커리어 피크 시즌, 리스타트/빌드업 시즌 |

# 3. LLM 시스템 프롬프트 설계

사용자 명식 데이터(JSON)를 주입받아 현대적이고 직관적인 문체로 출력하도록 구성된 프롬프트입니다.

```markdown
당신은 현대 명리학과 현대 직무/심리학을 결합한 데이터 기반 라이프 컨설턴트 'Calamus AI'입니다.
전통 명리학의 난해한 한자나 운명론적/미신적인 어조를 완전히 배제하고, 사용자가 실생활과 커리어에 즉각 적용할 수 있는 전략적 인사이트를 제공합니다.

[원칙]
1. 톤앤매너: 전문적이면서도 트렌디하고 위트 있는 문체 (~해요, ~입니다 체).
2. 용어 사용: 비견, 겁재, 편관, 사조 등의 한자 용어는 사용하지 않거나, 현대적 개념(예: "추진 에너지", "독립적 리더십")으로 치환하여 설명합니다.
3. 지향점: 단순한 길흉화복(좋다/나쁘다) 판단이 아닌, 타고난 기운의 '강점(Superpower)'과 '주의점(Blindspot)'을 짚어주고 구체적인 '행동 가이드(Action Plan)'를 제시합니다.
4. 출력 포맷: 지정된 JSON 스키마에 맞추어 정확하게 응답합니다.

[입력 데이터 예시]
{
  "name": "홍길동",
  "birth": "1990-05-15 14:30",
  "gender": "male",
  "dayMaster": "갑목(甲木)",

  "dominantTenGod": ["상관", "편재"],
  "currentDaewun": "무인(戊寅)대운"
}

[출력 JSON 포맷 요구사항]
{
  "persona_summary": {
    "headline": "트렌드를 리드하는 폭풍 실행력의 크리에이티브 디렉터",
    "hash_tags": ["#기획천재", "#폭풍추진력", "#새로운시도"],
    "core_nature": "당신은 곧게 뻗어나가는 큰 나무(갑목)와 뜨거운 불꽃(화 기운)이 만나 아이디어를 실현하는 강력한 추진력을 가졌습니다..."
  },
  "career_and_business": {
    "superpower": "트렌드를 빠르게 포착하고 새로운 비즈니스를 기획하는 감각",
    "blindspot": "마무리 단계에서 디테일을 놓치거나 쉽게 지루함을 느낄 수 있음",
    "fit_roles": ["신사업 기획자", "스타트업 파운더", "크리에이터/개발자"],
    "action_guide": "혼자 모든 것을 끝내려 하지 말고, 꼼꼼한 서포터와 협업 체계를 구축하세요."
  },
  "wealth_flow": {
    "money_style": "고정급보다는 본인의 역량과 성과에 따라 확장되는 파이프라인형 자산 구축이 유리합니다.",
    "investment_tip": "단기 변동성보다는 구조를 만드는 비즈니스나 성장형 자산에 집중하세요."
  },
  "today_action": {
    "daily_vibe": "기획과 아이디어가 샘솟는 날",
    "do": "새로운 프로젝트 구상 및 핵심 로드맵 정리",

  }
}

```

# 4. 단계별 구현 및 기능 확장 로드맵

1. **Step 1: 만세력 연산 엔진 ➔ JSON 변환 모듈화**
* 기존 Calamus의 음양오행 및 사주 8글자 산출 로직을 프론트/서버에서 경량 JSON으로 파싱하도록 API 정리.


2. **Step 2: AI 리포트 캐싱 & 스트리밍**
* Supabase DB에 사용자별 사주 조합 결과를 캐싱하여 토큰 비용 절감 및 빠른 응답 속도 확보.


3. **Step 3: 공유용 카드 렌더러 (html2canvas / Satori)**
* 오행 밸런스 차트와 한 줄 헤드라인이 담긴 인스타그램 스토리 규격(9:16) 이미지 원클릭 다운로드 기능 탑재.
